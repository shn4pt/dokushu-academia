独習アカデミアの移行のご案内

学習の進捗は、このブラウザの中(この URL のオリジン)にだけ保存されています。新しい URL に移ると、進捗は自動では引き継がれません。次の手順で、書き出して、新しい側で読み込みます。

このブラウザの保存データ

保存データの確認には、JavaScript が必要です。

手順

  1. 先に、バックアップを取る。上のボタン(「進捗を書き出す」。書き出せない状態では「元の保存データを、そのまま保存する」)を押して、ファイルを保存します。移動の前に、必ず保存してください。
  2. 下の「新サイトを開く」から、新しい URL を開きます。
  3. 新サイトの「進捗と設定」で、「インポート」を押し、保存したファイルを選びます。

新サイトにすでに進捗がある場合: 「インポート」は、新サイトの進捗を、読み込んだファイルの内容で置き換えます(混ぜ合わせません)。置き換える前に、新サイトの側でも「エクスポート」を押して、バックアップを取ってください。読み込んだ後は、完了数・クイズの記録が、想定どおりか確認してください。

引き継がれないもの・注意: 自己診断の回答と、API の設定(キーなど)は、書き出しの対象外です。通常の「進捗を書き出す」は、既知の進捗の項目だけを対象にし、自己診断の回答や API 設定の保存先は、読みません(進捗の項目に、利用者が何を書いたかまでは、保証できません)。一方、「元の保存データを、そのまま保存する」は、検証できていない文字列もそのまま含むため、API キーなどが含まれないとは、保証できません。外部に共有しないでください。新サイトで、必要なら API の設定を入力し直してください。

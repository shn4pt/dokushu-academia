### この講座の範囲と、確認した日

[前のレッスン](/lesson/lg-3)に続いて、事業で必ず出会う**個人情報**の扱いを、**個人情報の保護に関する法律**(以下「個人情報保護法」)の条文が書く**全体像と考え方**に限って見ます。自社がどの情報を個人情報として扱うか、利用目的をどう書くか、第三者提供に同意が要るか、漏えいが起きたときの報告の要否、といった**個別の事案は扱いません**。それらは、**弁護士などの専門家に確認**してください。このレッスンの内容は、法律の助言ではありません。

**確認した日**は 2026-10-12 です。読んだ原典は、e-Gov 法令検索の、**個人情報の保護に関する法律**の、第 1・2・16〜28・32・33 条の本文です(2026-10-01 施行の版)。**政令、個人情報保護委員会規則、委員会のガイドラインは、読んでいません**。条文が、これらに委ねている点が多いので、実際の対応には、それらを確認する必要があります。

### 法律の目的

第 1 条は、この法律の目的を、次のように定めます(要点)。デジタル社会の進展に伴い個人情報の利用が著しく拡大していることに鑑み、個人情報の適正な取扱いに関する施策の基本となる事項を定め、個人情報を取り扱う事業者や行政機関等が**遵守すべき義務等**を定めるとともに、**個人情報保護委員会**を設置することにより、**個人情報の有用性に配慮しつつ、個人の権利利益を保護する**。

つまり、**個人情報の活用と、個人の権利利益の保護の、両方**が、条文の中に書かれています。

### 用語:個人情報と、その仲間

第 2 条、第 16 条は、次の用語を定めます(要点)。

| 用語 | 条文の定義(要点) |
|---|---|
| **個人情報** | **生存する個人**に関する情報で、(1)氏名、生年月日その他の記述等により**特定の個人を識別できるもの**(**他の情報と容易に照合でき、それにより識別できることとなるものを含む**)、または、(2)**個人識別符号**が含まれるもの(第 2 条第 1 項) |
| **個人識別符号** | 身体の一部の特徴を電子計算機のために変換した符号で、特定の個人を識別できるもの、または、役務の利用や商品の購入に関して割り当てられ、またはカードなどに記載・記録された符号で、利用者や購入者を識別できるもの、のうち**政令で定めるもの**(第 2 条第 2 項) |
| **要配慮個人情報** | 本人の人種、信条、社会的身分、病歴、犯罪の経歴、犯罪により害を被った事実その他、不当な差別、偏見その他の不利益が生じないようにその取扱いに特に配慮を要するものとして政令で定める記述等が含まれる個人情報(第 2 条第 3 項) |
| **仮名加工情報** | 個人情報を、定められた措置を講じて、**他の情報と照合しない限り**特定の個人を識別できないように加工して得られる個人に関する情報(第 2 条第 5 項) |
| **匿名加工情報** | 個人情報を、定められた措置を講じて、**特定の個人を識別できないように**加工して得られる個人に関する情報で、**個人情報を復元できないようにしたもの**(第 2 条第 6 項) |
| **個人関連情報** | 生存する個人に関する情報で、個人情報、仮名加工情報、匿名加工情報の**いずれにも該当しない**もの(第 2 条第 7 項) |
| **個人情報データベース等** | 個人情報を含む情報の集合物で、特定の個人情報を**電子計算機を用いて検索できる**ように体系的に構成したもの、など(第 16 条第 1 項) |
| **個人データ** | 個人情報データベース等を**構成する**個人情報(第 16 条第 3 項) |
| **保有個人データ** | 個人情報取扱事業者が、開示、訂正、利用の停止、消去、第三者への提供の停止を行える権限を有する個人データ(例外あり)(第 16 条第 4 項) |

(**生存する個人**に関する情報であること、が個人情報の要件です。個々の情報が、個人情報にあたるか、要配慮個人情報にあたるかは、政令などに委ねられる部分があるので、**専門家に確認**してください。)

### 誰に義務がかかるか

第 16 条第 2 項は、**個人情報取扱事業者**を、**個人情報データベース等を事業の用に供している者**と定めます。ただし、国の機関、地方公共団体、独立行政法人等、地方独立行政法人は除きます。この項には、**取り扱う個人情報の件数の下限は、書かれていません**(読んだ範囲です)。個人事業主や、小さな会社でも、個人情報データベース等を事業の用に供していれば、条文上は、あてはまり得ます。自社があてはまるかは、**専門家に確認**してください。

### 取り扱いの流れと、条文

個人情報取扱事業者の義務を、取り扱いの段階ごとに整理します(各条の要点です。例外などの細部は、読んでいない部分があります)。

| 段階 | 条文 | 要点 |
|---|---|---|
| 取得 | 第 17 条第 1 項 | 利用の目的(**利用目的**)を、**できる限り特定**しなければならない |
| | 第 20 条第 1 項 | **偽りその他不正の手段**により、個人情報を取得してはならない |
| | 第 20 条第 2 項 | **要配慮個人情報**は、次の場合を除き、**あらかじめ本人の同意**を得ないで取得してはならない。例:法令に基づく場合、人の生命・身体・財産の保護のために必要で、同意を得ることが困難なとき、本人などにより**公開**されている場合、など |
| | 第 21 条 | 取得した場合は、**あらかじめ利用目的を公表**している場合を除き、**速やかに**、利用目的を本人に**通知**または**公表**しなければならない。**契約書などの書面で本人から直接取得する場合**は、**あらかじめ、利用目的を明示**しなければならない(ただし書あり)。利用目的を変更した場合も、通知または公表(第 3 項)。第 4 項に、適用しない場合の定めがある |
| 利用 | 第 18 条第 1 項 | あらかじめ**本人の同意**を得ないで、特定された利用目的の**達成に必要な範囲を超えて**、個人情報を取り扱ってはならない(例外は第 3 項) |
| | 第 17 条第 2 項 | 利用目的の変更は、変更前と**関連性を有すると合理的に認められる範囲**を超えてはならない |
| | 第 19 条 | **違法または不当な行為を助長し、または誘発するおそれがある方法**により、個人情報を利用してはならない |
| 保管 | 第 22 条 | 利用目的の達成に必要な範囲内で、個人データを**正確かつ最新**の内容に保つとともに、利用する必要がなくなったときは、**遅滞なく消去する**よう**努めなければならない** |
| | 第 23 条 | 個人データの**漏えい、滅失、毀損の防止その他の安全管理**のために、**必要かつ適切な措置**を講じなければならない |
| | 第 24 条 | 従業者に個人データを取り扱わせるときは、必要かつ適切な**監督**を行わなければならない |
| | 第 25 条 | 個人データの取扱いを**委託**する場合は、委託を受けた者に対する必要かつ適切な**監督**を行わなければならない |
| 事故 | 第 26 条第 1 項 | 個人データの漏えい、滅失、毀損その他の安全の確保に係る事態で、**個人の権利利益を害するおそれが大きいものとして個人情報保護委員会規則で定めるもの**が生じたときは、規則で定めるところにより、**個人情報保護委員会に報告**しなければならない。他の事業者などから委託を受けた場合で、規則で定めるところにより、**委託元に通知**したときは、この限りでない |
| | 第 26 条第 2 項 | 上の場合は、本人に対しても、規則で定めるところにより、当該事態が生じた旨を**通知**しなければならない(ただし書あり) |
| 提供 | 第 27 条第 1 項 | 次の場合を除くほか、**あらかじめ本人の同意**を得ないで、個人データを**第三者に提供**してはならない。例:法令に基づく場合、人の生命・身体・財産の保護のために必要で、同意を得ることが困難なとき、など |
| | 第 27 条第 5 項 | 次の場合の提供を受ける者は、第三者に**該当しない**。(1)利用目的の達成に必要な範囲内で**取扱いの全部または一部を委託**することに伴う提供、(2)合併その他の事由による**事業の承継**に伴う提供、(3)特定の者との間で**共同して利用**される個人データの提供(条件あり) |
| | 第 27 条第 2 項 | 第三者に提供される個人データについて、**本人の求めに応じて第三者への提供を停止**することとしている場合で、一定の事項を、規則で定めるところにより、あらかじめ**本人に通知し、または本人が容易に知り得る状態に置く**とともに、**委員会に届け出た**ときは、第 1 項の規定にかかわらず、第三者に提供できる(いわゆるオプトアウト。ただし、**要配慮個人情報など**は、この方法では提供できない。細部は読んでいません) |
| | 第 28 条 | **外国にある第三者**への提供は、別の制限がある(個人情報保護委員会規則で定める基準に適合する体制を整備している者などを除き、あらかじめ外国にある第三者への提供を認める旨の本人の同意が要る、など。細部は読んでいません) |
| 本人への対応 | 第 32 条 | 保有個人データに関し、事業者の氏名・名称・住所、**全ての保有個人データの利用目的**、開示などの請求に応じる手続、などを、**本人の知り得る状態**に置かなければならない |
| | 第 33 条 | 本人は、識別される保有個人データの、電磁的記録の提供による方法などによる**開示を請求できる**。事業者は、遅滞なく開示しなければならない(開示しないことができる場合も、同条第 2 項に定める) |

(第 34 条以下の訂正等、利用停止等の請求の規定は、このレッスンでは読んでいません。第 32 条第 1 項第 3 号が、それらの請求に応じる手続を本人の知り得る状態に置くことを求めていることから、そうした請求の規定があることが分かります。)

### 委員会規則や政令に委ねられている点

条文は、細部を、**政令**や**個人情報保護委員会規則**に委ねている点が多くあります。例えば、次の点です。

- 個人識別符号、要配慮個人情報の、具体的な範囲(第 2 条。政令)
- 報告が必要な**漏えい等の事態**の範囲と、報告の方法(第 26 条。委員会規則)
- 外国にある第三者への提供の、基準に適合する体制、我が国と同等の水準にある制度を有する外国(第 28 条。委員会規則)
- 開示の方法(第 33 条。委員会規則)

[法務-1](/lesson/lg-1)で見たとおり、**委ねられた先**まで読む必要があります。このレッスンは、委ねられた先を読んでいません。

### 事業での考え方(このサービスの整理)

条文の流れから、このサービスは、次のように整理します。これは、条文の記述ではなく、このサービスの整理です。

- **取得の前に、何のために使うかを決める**(第 17 条)。目的が決まらないと、通知・公表(第 21 条)も、同意の範囲(第 18 条)も、定まらない。
- **誰が、どこまで取り扱うか**を、決めておく(従業者の監督、委託先の監督:第 24・25 条)。
- **事故が起きる前に、起きたときの流れ**を決めておく(第 26 条は、報告の義務を定めるが、対象となる事態は規則に委ねられている)。
- **本人からの請求**(開示など)に答えられる状態にしておく(第 32・33 条)。

### 改正の予定(確認した日:2026-10-12)

e-Gov には、**将来施行の版が 6 つ**(2026-11-02、2027-01-17、2027-04-01、2027-04-16、2028-07-16、2028-12-23)あります。引用した条を比べた結果は、次のとおりです。

- **2026-11-02 から 2027-04-16 までの 4 つの版**:引用した条のうち、**第 2 条**だけが変わります。変わるのは、**行政機関**の定義(防災庁に関する規定の追加)で、事業者の義務にかかわる定義(個人情報、要配慮個人情報、仮名加工情報、匿名加工情報、個人関連情報)は、同じです。**第 16〜28・32・33 条**は、現行と同じです。
- **2028-07-16 施行の版(と、2028-12-23 の版)**:**第 16・18・20・26・27・28・32・33 条**の文言が変わります。主な変更は、次のとおりです(読んだ範囲の例です)。
  - **第 2 条**:**連絡可能個人関連情報**(第 8 項)と**統計作成等**(第 13 項)の定義が加わる。
  - **第 18 条第 3 項、第 20 条第 2 項、第 27 条第 1 項**:例外のうち、「本人の同意を得ることが困難であるとき」に、**「その他本人の同意を得ないことについて相当の理由があるとき」**が加わる。また、**本人との間の契約の履行のために必要やむを得ないことが明らかである場合その他、取得の状況からみて本人の意思に反しないため本人の権利利益を害しないことが明らかである場合として、委員会規則で定める場合**が、例外に加わる。
  - **第 26 条第 2 項**:本人への通知のただし書に、**本人への通知が行われなくても、本人の権利利益の保護に欠けるおそれが少ない場合として委員会規則で定める場合**が加わる(代わりの措置をとることは、引き続き要件)。
  - **第 27 条**:第 2 項のオプトアウトで提供できない情報に、**特定生体個人情報**が加わり、第 2 項により提供するときの**確認**の義務(第 7 項など)が加わります(細部は読んでいません)。第 16 条には、特定生体個人情報の定義(第 5 項)が加わります。また、新たに**第 21 条の 2** が設けられます(特定生体個人情報に関する規定とみられますが、内容は読んでいません)。
  - **第 32 条、第 33 条**:請求に応じる手続の書き方の整理(第 32 条)、開示方法の「その他の事情」への表現の変更(第 33 条)。
- 引用していない条にも、改正があります(中身は読んでいません)。

つまり、**個人情報保護法は、確認した日の時点で、すでに大きな改正が公布されていて、2028 年に主要な条の文言が変わる**ことが、条文から分かります。実際の対応では、**施行日ごとの版**を確認してください。

次のようなことは、このレッスンの範囲を超えます。**弁護士などの専門家に確認**してください。

- 自社が扱う情報が、個人情報、個人データ、要配慮個人情報にあたるか。
- 利用目的の書き方、通知・公表の方法。
- 第三者提供にあたるか(委託、事業承継、共同利用との区別を含む)。同意が要るか。

- 本人からの開示などの請求への対応。
- 従業員、取引先、顧客の個人情報の扱い。

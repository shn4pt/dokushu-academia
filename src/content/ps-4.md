### 動機づけとは、何か

OpenStax の *Psychology 2e* は、**動機づけ(motivation)**を、**行動を目標に向ける、欲求や必要**と定義します。生物学的な動機に加えて、動機は、内側から生じる**内発的**なものと、外側から生じる**外発的**なものに分けられます。

- **内発的動機づけ**:その行動がもたらす個人的な満足のために行う。
- **外発的動機づけ**:他者から何かを得るために行う。

教科書は、現実の動機は、両方の混ざったもので、その混ざり方は、時間とともに変わる(直感に反する形で変わることもある)と述べます。

### 古い理論:本能、動因、覚醒、自己効力

教科書は、動機づけの理論を、次のように紹介します。

- **本能理論**:William James は、行動が、生存を助ける**本能**で動かされると考えた。しかし、本能の定義と一覧が人によって異なり、学習の役割を無視しているという批判があった。
- **動因理論**:体の**恒常性**(バランスの維持)が崩れると、生理的な欲求が生じ、**動因**(たとえば空腹)が、その欲求を満たす行動に向かわせる。そして、動因を下げた行動は、習慣になりやすい。
- **覚醒理論**:人は、最適な覚醒の水準を保とうとする。覚醒が低すぎると退屈して刺激を求め、高すぎると下げようとする。**Yerkes-Dodson の法則**は、最適な水準が課題の複雑さによって変わり、**単純な課題は高めの覚醒で、複雑な課題は低めの覚醒で**、最もうまくいく、と述べる。
- **自己効力感**:Bandura(1994)は、自分がその課題をやり遂げられるという信念が、行動を動機づけると論じた。
- **社会的な動機**:達成、親和、親密などの欲求(McClelland、Murray ら)。

教科書は、**Maslow の欲求階層**(1943)も紹介します。生理的欲求、安全、愛と所属、承認(自尊)、**自己実現**の順に、ピラミッドで表します。下位の欲求が満たされてから、上位の欲求に向かう、と Maslow は述べました。教科書は、この理論が、**主観的で、現実世界の現象を説明できない**として批判されている、とも述べます。

### 自己決定理論:内発的動機づけを、何が支えるか

Ryan と Deci(2000)の論文は、**自己決定理論(self-determination theory, SDT)**の総説です。この論文は、**理論の提唱者自身**が書いたものです(この点は、後の「限界」で触れます)。

**3 つの心理的欲求。** SDT は、人に生まれつきの 3 つの心理的欲求があると述べます。

- **有能感(competence)**:自分が、できる、という感覚。
- **自律性(autonomy)**:自分で選んで行動している、という感覚。
- **関係性(relatedness)**:他者とつながっている、という感覚。

これらが満たされると、自発的な動機づけと心の健康が高まり、妨げられると、動機づけと幸福感が下がる、と論文は述べます。論文は、**自律性は、独立や個人主義と同じではない**とも述べます(依存的な行動でも、自分で選んだ感覚があれば、自律的でありうる)。

**内発的動機づけ。** 論文は、内発的動機づけを、新奇さや挑戦を求め、能力を伸ばし、探索し、学ぶ、生まれつきの傾向だと説明します。この傾向は、**支えとなる条件がないと、簡単に損なわれる**とも述べます。論文が整理する**認知的評価理論**は、次のように述べます。

- 有能感を高める出来事(**最適な挑戦**、有能感を促すフィードバック、見下す評価がないこと)は、内発的動機づけを高める。ただし、**自律性の感覚**を伴わないと高まらない。
- **課題の遂行に応じた、予期された物質的報酬**や、**脅し、締め切り、指示、評価の圧力、押しつけられた目標**は、内発的動機づけを弱める。外側から動かされている感覚になるため。
- **選択、感情を認めること、自分で進める機会**は、高める。
- 教師や親が**自律性を支える**(支配的でない)と、子どもの内発的動機づけ、好奇心、挑戦する意欲が高い。支配的な教え方では、特に概念的・創造的な学習が、うまくいかない。

論文は、**内発的動機づけの理論が当てはまるのは、もともと興味を引く活動**に限る、とも断っています。

**外発的動機づけにも、自律の程度の違いがある。** SDT は、外発的動機づけを、一つのものとして扱いません。**自律の度合い**によって、次の連続体に並べます。

| 種類 | 内容 |
|---|---|
| 無動機 | 行う意図がない。価値を感じない、できると思わない、結果が出ると思わない |
| 外的調整 | 外からの要求や報酬のために行う。統制され、疎外された感じを伴う |
| 取り入れ的調整 | 罪悪感や不安を避ける、プライドを得るために行う。内側からの圧力だが、自分のものになっていない |
| 同一化的調整 | その行動の目標を、自分にとって大切だと意識して認めている |
| 統合的調整 | 同一化した調整が、ほかの価値や欲求と一致し、自分に完全に取り込まれている |
| 内発的動機づけ | 活動そのものの満足のために行う |

論文は、学校の例を挙げます。宿題を、自分のキャリアに必要だと理解して行う生徒も、親に従って行う生徒も、外発的に動機づけられていますが、前者は自分で選んだ感覚があり、後者は外的な調整に従っています。論文が紹介する研究では、外的調整が強い児童ほど、興味、価値、努力が低く、同一化的調整は、より多い興味と努力と結びついていました。

そして、**外発的な行動を、自分のものにしていく(内在化する)**には、**関係性**(大切な人とのつながり)と**有能感**の支えが助けになり、**自律性**の支えは、内在化を助けるうえに、取り込んだ調整が自分に**統合される**ために欠かせない、と論文は述べます。意味のある理由を説明し、自律性と関係性を支えると、興味のない行動でも内在化が進んだ、という実験を、論文は紹介します。

### 報酬は、動機づけを損なうのか:割れている結果

教科書は、**外的な報酬が、もともと楽しいことへの動機づけを下げるかどうか**について、研究の結果が割れている、と述べます。

- 下げるという研究(Deci, 1972 など)がある一方、**ほめ言葉**はむしろ内発的動機づけを高めうるという研究(Arnold, 1976。Cameron と Pierce, 1994)がある。
- 教科書は、この食い違いを、いくつかの要因で説明する。**金銭などの物質的な報酬**は、言葉の報酬より、内発的動機づけへの悪影響が大きい。また、**報酬を予期しているか**が重要で、予期していると下がりやすく、不意の報酬では保たれやすい(Deci ら, 1999)。

Deci、Koestner、Ryan(1999)のメタ分析の要旨(このサービスが読んだ範囲)は、128 件の研究を調べて、次のように述べます。

- 課題への取り組み、課題の完了、成績に、それぞれ応じた報酬(engagement-, completion-, performance-contingent。要旨に、定義は書かれていません)は、いずれも、**自由選択の場面での行動**(free-choice)という内発的動機づけの指標を、有意に下げた(効果量 d = -0.40、-0.36、-0.28)。
- 肯定的なフィードバックは、**高めた**(d = 0.33)。
- 物質的な報酬は、**児童のほうが、大学生より悪影響が大きい**傾向があった。

Ryan と Deci(2000)の論文は、このメタ分析が、Eisenberger と Cameron(1996)の主張に**反して**、成績に応じた、予期された物質的報酬が、内発的動機づけを損なうことを確認した、と述べます。つまり、**この点は、研究者の間で議論が続いた**問題です。(論文が述べるのは、課題の遂行に応じた、予期された物質的報酬の場合です。)

### 限界と読み方

- **SDT の総説は、理論の提唱者自身が書いたもの**です。第三者による批判的な検討や、追試の状況は、このレッスンでは確かめていません。Ryan と Deci の論文は、SDT に導かれた自分たちの研究群を、中心に紹介しています。
- 論文は、教育(児童・生徒)の研究を多く紹介しますが、医療、運動、介護施設、職場の研究も引いています。職場の研究(Baard ら, 1998)は、論文の時点では**未公刊の原稿**として引かれています。このレッスンは、これらの個々の研究を確かめていません。欲求の満足と幸福感の関係の研究も、論文が挙げるものは、欲求の満足の**報告**にもとづくものが多く見えます(論文自身は、この点を論じていません。これは、このサービスの読み方です)。
- Maslow の階層は、教科書が、主観的で現実の現象を説明できないと批判されていると述べます。階層の順序に実証的な根拠があるかは、このサービスは確認していません。
- 報酬の効果は、**報酬の種類**(物質的か言葉か)、**予期**、**対象**(児童か成人か)で変わります。「報酬は逆効果」と単純に言うのは、研究の読み方として不十分です。

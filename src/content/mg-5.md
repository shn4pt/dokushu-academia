### 組織の形は、どう選ぶのか

[マネジメント-4](/lesson/mg-4)までで、一人の管理職の仕事を見ました。チームが大きくなると、**誰が誰に報告し、仕事をどう分けるか**という、組織の形(構造)が問題になります。OpenStax の教科書 *Principles of Management*(CC BY 4.0)は、組織構造を「組織内の活動をつなぎ、達成するための仕組み」、組織設計を「組織の必要に合わせて構造を作る過程」と定義します。このレッスンは、構造に関する 3 つの節(m70658、m70624、m70728)の本文を読みます。

最初に断っておくと、この教科書の構造の節は、**研究の集計ではありません**。分類の枠組み(Weber、Burns と Stalker、Daft など)を紹介します。事例(McDonald's、Amazon)は**実務家向けの記事**を引いており、6 つの型の節は、学術書・論文と実務家向けサイトが混ざった出典リストを掲げますが、個々の利点・欠点がどれに由来するかは、本文から分かりません。「どの構造がよい成果を出すか」を比べた結果は、本文では報告されていません(引用先の論文に含まれるかは、確認していません)。

### 公式の組織と、非公式の組織

教科書は、組織を 2 つの面で見ます。

- **公式の組織**: 公式に定められた関係、責任、つながり。組織図が代表的な表現。
- **非公式の組織**: 人々が実際につながる、見えない人間関係の網。日々の会話や関係から**自然に生まれ**、複雑で、**統制できず**、組織の成功に大きく影響しうる。組織図とは**違う**形になる(関係図、「ネットワークマップ」で描ける)。本文には、「たいてい大きく違う」という文と、「たいてい公式の組織と近いが、違うことも多い」という文の**両方**があり、どちらが多いかは、本文からは決められません。

教科書は、「**公式の組織は、組織がどう機能すべきかを説明し、非公式の組織は、実際にどう機能しているかを表す**」とまとめます。非公式の組織は、組織の成功を助けも妨げもする、とも述べます。管理職は、人々が一緒に働いて関係を築く機会を与えることで、非公式の組織の形に**影響はできる**、と述べます(直接には支配できない)。

### 官僚制の 5 つの要素

教科書は、Max Weber の官僚制のモデルを、「よく使われる枠組みの一つ」として紹介します。Weber の基本の仮定は、**仕事を分け、専門化させ、階層の中で調整すれば、効率が上がる**というものです。教科書は、判断の土台となる 5 つの要素を挙げます(Weber の 1958 年の論文集を引用)。

| 要素 | 意味(教科書の説明) |
|---|---|
| **専門化** | 専門分野(人事、財務、マーケティング、製造など)ごとに、部署に分ける度合い |
| **指揮命令(command-and-control)** | 誰が誰に報告し、どうつながって、調整するか |
| **管理の幅(span of control)** | 一人が責任を負う仕事の範囲 |
| **集権化** | 資源と意思決定の権限が、少数に集中しているか、広く分散しているか |
| **公式化** | 役割の定義の細かさ(軍は高く、小さなボランティア団体は低い) |

教科書は、この 5 つを Weber の要素として述べます。私は Weber の原典を読んでいないので、**この 5 つが Weber 自身の列挙かどうかは確認していません**。

### 機械的な構造と、有機的な構造

教科書は、5 つの要素の組み合わせを、2 つの極にまとめます(Burns と Stalker、Mintzberg などを引用)。

| | **機械的(mechanistic)** | **有機的(organic)** |
|---|---|---|
| 標準化 | 高い(公式化が強い) | 低い |
| 専門化 | 高い、狭い | 低い、広い |
| 権限 | 集権的 | 分権的 |
| 階層 | 縦に高い(階層が多い)。管理の幅は狭い | 平らで(階層が少ない)、管理の幅は広い |
| 向く環境 | 安定していて単純、不確実性が低い〜中程度 | 不安定で複雑、変化が速い |
| 例(教科書) | 米国郵政公社や製造業 | ハイテク、コンピュータ、航空宇宙、通信 |

教科書は、「**目的が革新なら有機的、信頼性なら機械的**」が必要になる、と述べます。管理の幅については、「幅を広げると階層が平らになり、狭めると階層が強まる」と述べます。さらに、**組織全体や、その一部**が、すべて有機的である必要はない、とも述べます。

### 6 つの構造の型

教科書は、**米国での**構造の歴史を 3 つの時代に分けます(Anand と Daft、2007 を引用)。(1) 1800 年代半ば〜1970 年代末は、機械的で、上意下達の、内向きの階層、(2) 1980 年代〜1990 年代半ばは、競争の激化(自動車産業での日本との競争など)と、パソコンやネットワークの普及で、**横断的な「水平組織」**が現れた、(3) 1990 年代半ば以降は、インターネット、世界規模の競争、サプライチェーンの自動化、外部委託で、組織の壁が低くなった、という整理です。

そのうえで、**6 つの型**を紹介します。

| 型 | 内容と、教科書が挙げる利点・欠点 |
|---|---|
| **機能別** | 部署や専門領域(研究開発、製造、会計、人事など)で分ける。最も古く、よく使われる。**利点**: 専門性が高い、報告が単純、規模の経済、拡大しやすい。**欠点**: 部署が孤立して「サイロ」になる、部署をまたぐ意思決定と調整が遅い、権力と資源を争う。 |
| **事業部別** | 機能別の部署を、事業部長の下にまとめ、市場、地域、製品ごとに分ける。**利点**: 事業と予算に集中できる、責任が分かりやすい、顧客への対応が速い、事業部内の調整が楽、本社が細かく管理しなくてよい。**欠点**: 事業部が孤立する、会計などの仕組みの連携が弱く、本社の使命・方向・価値観が伝わりにくい、システムが合わなくなる。 |
| **地域別** | 顧客のいる地域で分ける(事業部別の延長)。地域の顧客のニーズや文化に合わせやすい。利点・欠点は事業部別と似ていると、教科書は述べる。本社は、自律した地域を、調整・統制する必要がある。欠点は、意思決定が分散しやすいこと。 |
| **マトリクス** | 機能別の縦の線と、製品・プロジェクトの横の線を組み合わせ、**二重の報告関係**を持つ。1960 年代の米国の航空宇宙企業が、政府の契約で、プロジェクト管理の体制を示す必要があったことから生まれた(Britannica を引用)。**利点**: 柔軟、情報共有と調整が速い。**欠点**: 二人の上司に報告する混乱と対立、**忠誠心が分かれる**。成功には、対人コミュニケーション、対立の管理、政治的なスキルが要る。 |
| **ネットワーク型のチーム** | 最初の割り当ての後、課題や機会に応じて、メンバーが助けを求めて自然に形成する、非公式で柔軟な形。**欠点**: 連絡の線と期日を明確にする必要、技術(インターネット、電話)への依存、物理的に集まる場所がないことによる、誤りや関係の緊張、納期の遅れ。 |
| **バーチャル** | 情報通信技術に依存し、本部が唯一の、または一部の安定した拠点という「境界のない組織」(1990 年代に登場)。**利点**: 費用の節約、顧客への対応時間の短縮、多様な人材への接点、環境への影響の低減。**欠点**: 社会的な孤立、情報が少ないときの信頼の欠如、協力の減少。 |

教科書は、大企業では、**複数の構造を組み合わせて**使う、と述べます。構造は、**外部の環境に合わせて、組織が目標を達成できるように設計する**もの、とも述べます。

別の節(m70658)では、構造を「製品別」「地域別」と分け、これらを「機能的な構造」(職能のまとまりを持つ)と呼びます。**同じ教科書の中で、分類の呼び方が節によって違います**(6 つの型の節では、事業部別と地域別を並べる)。この「機能的」は、「組織の成功に必要な、環境上の特徴(functional need)」に由来する語です。このレッスンは、6 つの型の節の分類に合わせました。

### 構造は、環境と内部の要素に合わせる

教科書は、組織を**オープンシステム**(環境から資源を取り込み、組織内で変換し、環境へ戻す)として説明します(Katz と Kahn、von Bertalanffy を引用)。環境への感度の高低で、開いている/閉じている度合いが違う、と述べます。1980 年代に、米国の自動車大手 3 社が、日本の小型車に押された例を、教科書は「**閉じた(少なくとも環境に鈍感な)組織になっていたようだ**」と述べます。

組織は、構造だけでなく、**どの領域(ドメイン)で競争するか**を選ぶことでも環境に応じる、と述べ、内部の要素として、リーダーシップ、戦略、文化、経営、目標、マーケティング、運営、構造を挙げ、**McKinsey の 7S モデル**(戦略、構造、システム、スキル、人材、スタイル、共通の価値)も紹介します。教科書は、Lewin と Stephens の統合モデルとして、**経営者が環境を見て、SWOT で領域を確認し、ビジョン・使命・目標・戦略を決めたあとで、文化、構造などを整える**という順序も述べます。

事例として、McDonald's(世界規模で標準化された商品を、予測できる量・品質・費用で売る)と、Amazon(機能別の世界規模のグループ、世界規模の階層、地域別の事業部。この構造は、新しい問題への素早い対応を妨げうる、という分析記事を引用)を挙げます。**これらは、実務家向けの記事を引いた 2018 年前後の記述で、今の組織の姿とは限りません**。

### 言えること、言えないこと

**言えること**: 教科書は、公式と非公式の組織、官僚制の 5 つの要素、機械的と有機的の対比、6 つの構造の型と、それぞれの利点・欠点、環境と構造の関係を整理している。

**言えないこと**:
- **どの構造が、どの環境で、よい成果を出すか**。教科書は、「この環境に向く」と主張するが、その根拠となる、構造どうしの成果の比較は、本文で報告されていない(引用先の論文に含まれるかは確認していない)。
- 6 つの型の利点・欠点が、**実際の組織で、どの程度起こるか**。個々の記述の出典は、本文から分からない。
- 官僚制の 5 つの要素が **Weber 自身の列挙か**(原典は読んでいない)。
- **日本の組織**(職能別の人事制度や、部・課の構造など)にそのまま当てはまること。
- Amazon や McDonald's の記述が**現在も正しい**こと。
- 引用された文献の原典は、読んでいません。

### 組織の形を考える前の問い(このサービスの整理)

ここからは、このサービスの整理です。教科書の内容を、チームや組織の見直しに移したものです。

1. **今、実際に仕事が流れている関係(非公式)は、組織図と、どう違うか。**
2. **事業の環境は、安定しているか、変化が速いか。** どちらの極に近い形が合うか。
3. **今の構造の欠点(サイロ、二重報告の混乱、孤立など)が、実際に起きているか。**
4. **管理の幅は、管理職が見られる範囲か。** 広げるなら、部下に任せる準備はあるか。
5. **意思決定の権限は、どこにあるべきか。** 集中と分散のどちらが、今の目的に合うか。
6. **二重の報告関係を作るなら、対立を調整する仕組みと、必要な技能があるか。**
7. **構造を変えれば仕事のやり方が変わると、決めつけていないか。** (次のレッスンで見る、変革の進め方の問題です。)

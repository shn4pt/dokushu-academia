### 序論:経営企画の仕事

[マネジメント-2](/lesson/mg-2)で、目標が計画の出発点だと見ました。[経営-4](/lesson/sg-4)で、戦略を、[会計-5](/lesson/ac-5)で、予算を見ました。**経営企画**は、これらをつなぐ仕事です。会社の方向を決める計画を作り、各部署の計画を調整し、数字に落とします。このレッスンは、教科書が**「計画」と「計画の専門家」**をどう説明するか、**計画は成果につながるのか**、その根拠は何かを見ます。

OpenStax の教科書 *Principles of Management*(CC BY 4.0)は、計画を「**管理職が目標を定め、それをどう達成するかを示す過程**」とします。**日本の会社の「経営企画部」の仕事を述べた本ではありません**。米国の経営管理の教科書の、計画の章です。

### 計画の種類

教科書は、計画を、5 つの観点で分類します。

| 観点 | 種類 | 内容(教科書の説明) |
|---|---|---|
| **階層** | 戦略計画 | 長期の構想、使命、どの事業をするか。組織を、環境と結びつける |
| | 管理計画 | 資源を内部の各部門に配分する。戦略計画と現場の計画をつなぐ |
| | 業務計画 | 日々の業務。技術的な中核 |
| **使用頻度** | 常設の計画 | 方針、規則、手順(標準業務手順 SOP)。繰り返し起こる問題に対応 |
| | 単発の計画 | プログラム、プロジェクト、**予算**(「数字で表した計画」) |
| **期間** | 短期、中期、長期 | 教科書の分類表では、短期は数時間〜1 年、中期は 1〜5 年、長期は 5 年超 |
| **範囲** | 事業・事業部の計画 | 一つの事業(事業部)と、その競争上の位置 |
| | 部署・機能別の計画 | マーケティング、人事、会計、生産など、下位の部署の日々の業務 |
| | 戦術的計画 | 事業部や部署が、戦略計画を達成するための計画 |
| **不測の事態** | 想定外への備え | 災害など、事態が起きた場合の代替案 |

なお、教科書は、**別の節**(戦略の実行の節)では、期間を「**1 年以内の短期**」と「**それ以上の長期**」の 2 つに分けています。**同じ教科書の中で、期間の分け方が節によって違います**。

### 計画の過程

教科書は、計画を、「将来を向き、包括的で、体系的で、統合され、(関係者と)調整された」ものが理想だとします(Lorange と Vancil、1977、Steiner、1969 を引用)。そして、次の **5 つのステップ**を述べます(Koontz と O'Donnell、1972 を引用)。

1. **現状の認識**: 組織の現在の状態、約束、強みと弱み、将来の構想。過去を理解する。
2. **成果の記述**(目標)を立てる。
3. **前提を置く**(premising): 計画が依拠する想定を表に出す。**計画の質は、前提の質で決まる**。環境を見て、将来の出来事の起こりやすさを想定する。
4. **行動の方針を決める**: 選択肢を探し、評価し、選ぶ。何を、いつ、どうやって、誰が行うかを書く。
5. **支える計画を作る**: 基本の計画を補う派生の計画(教科書の例: 離職を減らすために、週 5 日(40 時間)の勤務から、週 4 日(40 時間)に変える計画には、残業の方針や会議の日程の計画が付く)。

教科書は、**目標型の計画**(具体的な目標を立ててから行動を考える)と、**領域型の計画**(ある方向・領域に進む。個別の目標は、進みながら絞る)を区別し、**ハイブリッド型**(最初は領域型で、学習が進むと目標型に移る)も挙げます。領域型が選ばれやすい場面として、柔軟性が要る、目標で合意できない、環境が不安定、立ち上げや移行の時期、を挙げます(3M の Post-it の開発を例に)。また、「**目標型の計画は、領域型だけの計画より、成果が高い**」という研究があると述べます(Smith、Locke、Barry、1986。**教科書の脚注では、公刊されていない原稿**)。

計画は、**実行と統制と結びつく**と述べます。**統制**は、実際の活動を、計画の目標と比べ、ずれがあれば是正する活動で、**計画が、統制の基準を作る**。教科書は、計画を棚に置いたままにする組織が多いと述べ、**Deming サイクル(計画 → 実行 → 確認 → 改善)**を、学習を計画に組み込む方法として説明します(IBM-Rochester などが採用)。

### 実際の会社の計画

教科書は、実際の組織の計画を、次のように述べます。1 つ目の項目の、8.3%、83%、1 億ドルの文には、Reitz と Jewell(1985)の引用が付きます。

- 1950 年代には、米国の主要企業の約 **8.3%**(12 社に 1 社)が、長期計画の専任者を置いていた。1960 年代の終わりには、**83%**が長期計画を使っていた。今日では、売上高 1 億ドルを超えるほぼすべての米国企業が、正式な長期計画を作っていると推定される。多くの計画は 5 年先まで、約 20%は 10 年以上先まで(この最後の文には、引用も年代も付いていない)。
- 多くの管理職は、計画に抵抗する(時間がない、複雑、費用がかかる、目標を達成できない結果を恐れる)。計画を立てない管理職や、行動の直前に考える「過程の中の計画」(in-process planning)に頼る管理職もいる。教科書は、方向感覚のある人が即興で動くなら、後者もうまくいくと述べる。
- 計画を促す方法として、計画を促す風土、上位の管理職の支援と手本、計画の訓練、計画を促す報酬(新しい目標を達成できなくても罰しない)、作った計画を使うこと、を挙げる。

> **8.3%、83%、1 億ドルの数字は、1985 年の文献の引用です。**今日の数字ではありません。5 年・10 年の数字には、年代の記載がありません。どちらも米国の話で、日本の会社に当てはまるとは限りません。

#### 計画は、成果につながるのか

教科書は、「**証拠は多くないが**、計画をする企業は、しない企業より、財務的に成功しているという研究がある」と述べ、複数の文献(Mintzberg、Lindsay と Rue、Herold、Saunders と Tuggle、Thune と House、2017 年の報道記事)を挙げます。そのうえで、例として、次の 2 つを示します。

- 5 年間の投資収益率の**中央値**が、戦略計画をする企業で **17.1%**、しない企業で **5.9%**(Bowman、1976)。
- 大手商業銀行 **70 行**のうち、戦略計画の仕組みを持つ銀行のほうが、成果がよかった(Wood と LaForge、1979)。

教科書は、**計画には明らかな利益があるが、費用は大きくなりうる。研究は、計画に価値があると示唆する**と述べます。

> 上の 2 つの例は、**1970 年代**の研究です。比べているのは「計画をする企業」と「しない企業」です。教科書は、計画の利益を肯定的に書きますが、**因果を検証した研究だ**とは述べていません(この読みは、このサービスのものです)。教科書自身が、証拠は多くないと断っています。

### 計画の専門家

教科書は、組織が複雑になり、環境が不確実になるにつれ、**計画の専門家(planning specialists)**や**計画部門**を置く組織が多いと述べます(Boeing や Ford が、専門の計画スタッフを持つ。United Airlines では、危機管理計画を、計画の専門家が作った)。置く理由として、教科書は、(1) 計画は**時間がかかり、複雑**で、現場の管理職の手に余る、(2) 変化の激しい環境では、**想定外への備え**が要る、(3) 利害のある管理職や従業員にできない、**客観性**が要る、を挙げます。

計画スタッフの目標として、教科書は、(1) **経営陣の助言役**となり、現場の管理職が目標を達成する計画を作るのを**助ける**、(2) 各階層の複雑な計画を**調整**する、(3) 計画を作る**意欲・支援・技能**を提供する、を挙げます。

教科書は、古典的な考え方は「計画する人」と「実行する人」を分けるが、行動科学の理論は、**影響を受ける人を計画に参加させる**ことを勧める、と対比します(目標による管理は、参加型の計画の一つ)。

### 言えること、言えないこと

**言えること**: 教科書は、計画の種類、5 つのステップ、目標型・領域型・ハイブリッド型、計画と統制の関係、計画の専門家の役割を整理している。計画をする企業のほうが成果がよい、という研究がある、と述べる(ただし、証拠は多くない、とも述べる)。

**言えないこと**:
- **計画が、成果の原因であること**。教科書は、複数の研究を根拠に挙げ、1970 年代の 2 つを例示するが、因果を検証した研究だとは述べない。
- 米国企業の計画の**普及率**(8.3%、83% など)が、**今日**、または**日本**で当てはまること。
- **日本の会社の経営企画部**が、何をしているか。
- 領域型と目標型の**優劣**(引用が、公刊されていない原稿の場合を含む)。
- 引用された文献の原典は、読んでいません。事例の囲み記事(Innovu など)も、事実は確認していません。

### 出典と限界

OpenStax *Principles of Management* の、計画の過程の節(m70705)、計画の種類の節(m70706)、実際の組織の計画の節(m70708)、戦略を実行する計画の節(m70655。期間の分け方の確認のみ)の本文を読みました。教科書が引く文献(Koontz と O'Donnell、Smith ら、Reitz と Jewell、Bowman、Wood と LaForge など)の原典は読んでいません。

6. **計画の専門家に、何を期待しているか。**(助言、調整、客観性。)
7. **「計画をすれば成果が上がる」と思い込んでいないか。**

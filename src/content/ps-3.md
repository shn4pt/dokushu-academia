### 見えているのに、気づかない:注意

「なぜ、あれに気づかなかったのか」と思う場面があります。OpenStax の *Psychology 2e* は、**注意(attention)**が、何が知覚されるかを大きく左右すると説明します。

- **ボトムアップ**:環境の刺激が、注意を引きつける。レストランで会話に集中していても、皿が割れる音は、注意の「フィルター」を突破して気づかされる。
- **トップダウン**:目的に導かれ、ゆっくり、努力して、自分で制御する。鍵を探すとき、黄色い鍵のホルダーなら、カウンターやテーブルの上で黄色を探し、天井の扇風機の上は探さない。

注意が向いていないと、完全に見えているものにも気づかないことがあります。これを**非注意性盲目(inattentional blindness)**と呼びます。有名な実験が、Simons と Chabris(1999)です。参加者は、白と黒の服の人たちがバスケットボールをパスする動画を見て、白いチームのパスの回数を数えます。途中で、ゴリラの着ぐるみの人が、チームの間を通ります。教科書は、動画を見た人の**ほぼ半数が、ゴリラに気づかなかった**と述べます(ゴリラは 9 秒間、はっきり見えていた)。

この論文の要旨(このサービスが読んだ範囲)は、未知の対象に気づく可能性が、**その対象が、ほかの対象と似ているか**と、**注意を向けている課題の難しさ**に依存する、と述べています。一方、対象の場所が、注意している場所に近いかどうかは、気づきやすさに影響しないように見える、と述べています。教科書は、別の実験(Most ら, 2000)でも、画面の白か黒の図形に注意を向けた参加者の**約 3 分の 1**が、赤い十字に気づかなかったと述べます。

### 記憶のしくみ:符号化・貯蔵・検索

教科書は、**記憶**を、情報を**符号化(encoding)**し、**貯蔵(storage)**し、**検索(retrieval)**する過程の集まりだと説明します。コンピュータのたとえがよく使われます。

**符号化**には、努力しなくてもできるもの(昼食の細部)と、**努力が要るもの**(試験の内容)があります。教科書は、意味づけると、符号化がよくなる、と述べます。Craik と Tulving(1975)の実験では、単語について、字体(視覚)、音(聴覚)、意味(**意味的処理**)のどれを問うかで、あとの記憶が変わりました。**意味を処理した単語**が、最もよく覚えられました。この結果は、**処理水準(levels of processing)**と呼ばれる考え(Craik と Lockhart, 1972)と合います。深く考えるほど、よく覚える、という仮説です。自分に関連づけると、さらによく覚える傾向(**自己参照効果**)も、教科書は紹介します。

**貯蔵**は、Atkinson と Shiffrin(1968)のモデルでは、3 段階です。

1. **感覚記憶**:感覚の短い貯蔵(数秒まで)。価値がないと見なした情報は捨てられる。
2. **短期記憶**:一時的な貯蔵(15〜30 秒)。**リハーサル**(くり返し)で長期記憶に移る。(教科書は、短期記憶と作業記憶は同じではなく、短期記憶は作業記憶の構成要素だと断ります。ただし、容量の話では、並べて扱います。)
3. **長期記憶**:継続的な貯蔵。容量は、無限と考えられている。

教科書は、Baddeley と Hitch(1974)の**作業記憶**のモデルも紹介します。短期の貯蔵にはいくつかの形(視空間、音韻、エピソード・バッファ)があり、**中央実行系**が流れを制御する、という考え方です。

**短期記憶・作業記憶の容量**について、教科書は次の経緯を述べます。

- Miller(1956)は、先行研究を見渡して、人が保てる項目は 5〜9 個、つまり「**7 ± 2**」だと報告した。
- 近年の研究では、**4 ± 1**とされる(Cowan, 2010)。
- Cowan(2010)の要旨(このサービスが読んだ範囲)は、課題の要求で変わる「繰り返せる能力」と区別できる、より一定の中心的な記憶の貯蔵が、若い成人で**3〜5 個の意味のある項目**に限られる、と述べています。

教科書は、短期記憶の保持を弱める要因として、**時間による減衰**と**干渉**を挙げます。Peterson と Peterson(1959)では、3 文字の並びを、3 秒後には約 80%、18 秒後には約 10% しか思い出せませんでした。しかし、Keppel と Underwood(1962)は、**最初の試行だけ**を見て、**前に学んだ情報が、新しい情報を妨げる(順向干渉)**ことも影響していると示しました。

**長期記憶**は、**顕在記憶**(意識して思い出せる。出来事の**エピソード記憶**と、知識の**意味記憶**)と、**潜在記憶**(意識されない。自転車の乗り方などの**手続き記憶**、プライミング)に分かれる、と教科書は説明します。

### 記憶は、誤る

教科書は、記憶は**再構成**されると述べます。思い出すたびに、新しい出来事が加わったり、変わったりして、不正確になりえます。

**誘導(suggestibility)**の例が、Loftus と Palmer(1974)です。大学生 45 人に、車の事故の映像を見せ、「車が(smashed / collided / bumped / hit / contacted)したとき、どのくらいの速さでしたか」と尋ねました。「smashed」と聞いた人は、「contacted」と聞いた人より、**速い速度**を答えました。1 週間後に、割れたガラスを見たかを尋ねると(映像にはなかった)、「smashed」の群は、**2 倍を超える**確率で、見たと答えました。教科書は、**質問の言葉**だけで、記憶が変わりうると述べます。

教科書は、目撃証言の誤りが、冤罪の主要な原因の一つだと述べます(DNA 鑑定で無実が分かった事例を調べた Innocence Project による)。そして、捜査の手順(面通しで、どの人かを示唆する、選択を肯定する)が、証人の確信を強めうると述べます。対策として、**どの写真が容疑者かを知らない人**が面通しを行う、中立的な言葉で聞く(教科書が挙げるのは、子どもへの面接の研究です)、が提案されています。

**忘却**について、教科書は、次を挙げます。

- **忘却曲線**:教科書によると、Ebbinghaus(1885)は、無意味な音節のリストを自分で覚えて調べ、20 分後に 50%、24 時間後に 70% を忘れる、という結果を得た。最初に急に落ち、やがて落ち着く。
- **符号化の失敗**:そもそも覚えていない。1 セント硬貨の表を正しく選べないのは、細部を符号化していないためだと考えられる(Nickerson と Adams, 1979)。
- **干渉**:前に学んだことが新しいことを妨げる(順向)、新しく学んだことが前のことを妨げる(逆向)。
- Schacter(2001)の「**記憶の 7 つの罪**」:一過性、不注意、妨害(舌先現象)、誤帰属、被暗示性(前に述べた「誘導」と同じ語)、偏り、持続。

### 覚えるための方法

教科書は、記憶を助ける方法を、次のようにまとめます。(ここで挙げた方法については、教科書は効果の大きさを示していません。このサービスは、これらの方法の個々の研究を、確かめていません。)

- **精緻化リハーサル**:新しい情報を、すでに知っていることと結びつける。処理水準の考えにもとづく。
- **自己参照**:自分の言葉で書く、自分の経験と結びつける。
- **分散学習**:一度に詰め込まず、時間をおいて学ぶ。記憶の定着には時間がかかるため。
- **カードで仕分ける**:カードの表に問い、裏に答えを書き、正解と不正解に分けて、間違えたものを繰り返す。教科書は、すでに学んだことに時間を使いすぎるハイライトより、効率がよいと述べる。
- **干渉を避ける**:静かな時間に学ぶ。
- **睡眠と運動**:睡眠中に情報が整理され、長期記憶に定着する。有酸素運動が記憶によいことが、研究で示唆される、と教科書は述べる。
- **ニーモニック**、**チャンク化**(電話番号を 520-555-0467 のようにまとめる)。

ここからは、このサービスの整理です。教科書や論文が直接述べたものではなく、実験室の結果を、画面設計や利用者調査に広げた推論です。

- **作業記憶に限りがある**(4 個前後)という知見は、画面やスライドに、一度に出す項目の数を考えるときの手がかりになります。ただし、「4 個まで」と決めつけず、項目の意味づけ(チャンク)や、課題の違いで変わることに注意が要ります。

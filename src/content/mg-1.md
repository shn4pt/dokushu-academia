### 管理職は、何をしているのか

「マネジメント」と聞くと、計画を立て、指示を出し、決断する、落ち着いた仕事を思い浮かべるかもしれません。OpenStax の教科書 *Principles of Management* は、管理職の仕事の実態を調べた研究を引いて、その像に異を唱えるところから始めます。

この講座の根拠は、**教科書**(OpenStax の *Principles of Management*、CC BY 4.0)です。本文を読みました。教科書は、観察研究の部分には研究の出典を付けていますが、管理職の仕事の特徴の節の記述の多くは、出典が付いていません。このレッスンでは、**教科書が引く研究の年代と、出典が付いていない記述**に注意します。研究の原典は読んでいません。

### 定義

教科書は、マネジメントを「**組織の目標を達成するために、他の資源とともに、従業員の活動を、計画し、組織し、指揮し、統制する過程**」と定義します。

### 管理職の1日:断片的で、会話が中心

教科書は、管理職の仕事を観察した研究を、次のように挙げます(いずれも教科書の引用です)。

- **Mintzberg(1973)**: 経営者(CEO)の仕事を観察した。1 日の平均で、書面の連絡が 36 件、口頭の連絡が 16 件。ほとんどが別々の問題で、**多くは 9 分未満**。
- **Kotter(1999 年の論文。成功した総合管理者を 5 年間研究)**: 管理職は、**1 人で仕事をする時間は平均 25%**(その時間の多くは、自宅、飛行機、通勤中)。70% 以上を他の人と過ごす人が多く、90% に達する人もいた。話題は非常に幅広く、重要でない話も重要な話と並ぶ。「大きな決定」は会話の中ではまれで、伝統的な意味で命令を出すこともまれ。「1 つの問題の議論が 10 分を超えることはまれ」。
- **Sproull(1984)**: 1 日に 58 の活動、1 つあたり平均 9 分。
- **Stewart(1967)**: 4 週間のうち、**30 分間、中断なしで働けたのは 9 回だけ**。
- **Eccles と Nohria(1992)**: 管理職は、廊下での雑談、電話、1 対 1 の会議、大きな会議を含めて、時間の約 3 分の 2 を他の人と過ごす。
- **Mintzberg(2009)**: 時間の 3 分の 2 から 4 分の 3 が、口頭の活動。

教科書は、Mintzberg の言葉を引きます。「他の労働者と違い、管理職は、電話や会議から離れて仕事に戻ることはない。**こうした接触が仕事そのもの**だ」。そして、管理職の仕事は**会話が中心**で、聞く力と話す力、断片的な情報を記録して動かす力が要る、とまとめます。

### 管理職の10の役割

Mintzberg の研究から、教科書は、管理職の役割が、**3 つのまとまり**に整理されると述べます(教科書の整理です)。

| まとまり | 役割 | 内容(教科書) |
|---|---|---|
| 対人関係 | 看板(figurehead) | 組織の長として、儀礼的な務めを果たす(Mintzberg の研究では、CEO の接触時間の 12%) |
| | リーダー | 部下の仕事に責任をもつ。権限があるが、どれだけ力を発揮するかは、大部分は、リーダーシップで決まる |
| | 連絡 | 指揮系統の外に接触を作る。管理職は、部下と同じ程度の時間を、同僚や外部の人と過ごす。Stewart の研究(英国の中間管理職と上級管理職 160 人)では、**同僚と 47%、自分の部署の人と 41%、上司とは 12%** |
| 情報 | 監視者 | 環境を調べ、情報を集める。かなりの部分は口頭で、うわさや憶測も含む |
| | 周知者 | 特別な情報を、部下に伝える |
| | 広報担当 | 組織の外に情報を伝える |
| 意思決定 | 起業家 | 改善し、機会に対応する |
| | 障害処理者 | 危機などに、不本意ながら対応する |
| | 資源配分者 | 誰に、何を、いつ、どれだけ配分するかを決める |
| | 交渉者 | 予算、労使協約、紛争などで交渉する |

### 仕事は、何が変わらず、何が変わるか

教科書は、管理職の仕事の特徴を、次のように述べます。

- **時間が断片的**: 20 世紀後半から、需要は増え、1 日の時間は一定。働く時間を増やしても、効果は逓減する。
- **価値が競合し、役割が緊張する**(この記述に出典はない): 従業員は仕事の時間、顧客は速さと質、上司は設備や研修の費用、株主は投資収益を求める。管理職は、全員が最も望むものを与えられない。
- **仕事が過負荷**: 多くの企業で、組織を効率化し、中間管理職の層を減らした。残った管理職の多くで、部下の数が倍になった(この記述にも出典がない)。**古典的な管理論では、部下は最大 7 人**とされるが、現在は 20〜30 人の部下をもつ管理職もいる(教科書の記述で、数字の出典は示されていない)。
- **効率が、21 世紀の中心的な能力になる**(この記述にも出典がない)。
- **起業家の役割とリーダーの役割の重要性が増している**(教科書の見方)。

### 管理職のレベルと、必要な能力

教科書は、Katz(1974)の整理を引き、管理職を 3 つのレベルに分けます。**経営層**(組織全体と戦略的な方向に責任)、**中間管理職**(主要な部門に責任。他の管理職を監督することもある)、**第一線の管理職**(一般の従業員を監督し、日々の活動を行う)。

そして、必要な能力を 3 つに分けます。**技術的な能力**(自分の専門分野の道具や手順を使う)、**人間関係の能力**(人と働き、動機づけや集団の過程を理解する)、**概念的な能力**(情報を整理・分析し、組織を全体として捉える)。教科書は、経営層は、(ほとんどの場合、すべてではないが)概念的な能力がはるかに多く要り、技術的な能力は少なく、第一線の管理職は、一般に技術的な能力がより多く要る、と述べます。**人間関係の能力は、どのレベルでも重要**です(3 つの能力の整理には、Katz の名前は付いていません)。教科書は、「若い従業員が、第一線の監督を習得する前に、CEO のように考え、行動したがる、というよく聞く不満」にも触れます。

### 管理職は、計画するのか:意見の違い

教科書は、「管理職は本当に計画するのか」という問いで、**研究者の意見が分かれる**ことを、そのまま載せています。

- **Mintzberg(1975)**: 管理職が計画するときは、日々の行動の中で暗黙に行う。CEO の計画は「頭の中にだけある、柔軟だが、しばしば具体的な意図」で、管理職の仕事は、反省的な計画者を育てず、「刺激に即座に反応する人」を作る。
- **Carroll と Gillen(1984)**: 多くの研究を検討し、Fayol や Urwick らの古典的な管理の機能は、(一部の現代の管理論の著者が主張するような)「民話ではなく」、管理職が実際にしていること、すべきことの**妥当な抽象**だ。
- 教科書は、さらに、「多くの管理職は体系的に計画している」とも述べます(Mahoney ら、1963・1965、Hass ら、1969、Penfield、1975 を引用)。

教科書は、「計画には種類がある」という点で、両者を調整します。

### 言えること、言えないこと

**言えること**: 教科書が引く、1960 年代から 2000 年代の観察や研究のまとめでは、観察された管理職の仕事は、**短い、断片的な、会話中心**のものだった。教科書は、管理職の役割を 3 つのまとまり・10 の役割で整理し、レベルによる能力の違いを述べる。

**言えないこと**:
- 引用された研究は、**数十年前の観察や研究のまとめ**で、対象の国は(Stewart の英国と Guest の米国の製造業の監督者を除いて)教科書に書かれておらず、欧米である可能性が高い、研究ごとの対象の人数や、選び方は、教科書にほとんど書かれていない(Stewart の 160 人を除く)。**今日の管理職、または日本の管理職に、そのまま当てはまるとは言えない**。
- 「部下は最大 7 人」「現在は 20〜30 人」という数字には、**出典が示されていない**。
- 3 つの能力とレベルの対応は、教科書の整理で、**実証的な比率は示されていない**。
- 管理職が計画するかどうかは、研究者の間で**意見が分かれている**。

### 自分の仕事を見直す問い(このサービスの整理)

ここからは、このサービスの整理です。

1. **1 日のうち、1 人で集中できる時間はどれだけあるか。** 中断なしの 30 分は、何回あるか。
2. **時間を、誰と過ごしているか。** 部下、同僚、外部、上司の割合。
3. **自分は、どの役割に、時間をかけているか。** 重要だが、後回しにしている役割はないか。
4. **自分のレベルに必要な能力は何か。** 技術・人間関係・概念の、どれを伸ばすか。
5. **聞くことと話すことに、意識的に時間を使っているか。** 会話が仕事の中心なら、その質が仕事の質になる。

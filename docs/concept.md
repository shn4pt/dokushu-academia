# コンセプト(下書き): AI と作る独習プラットフォーム

2026-10-09 のインタビューでまとめた。名前は未定。確定ではなく、作りながら見直す。

## 背景
事業会社のプロダクトマネージャーとして、経営・マーケティング・マネジメント・プロダクトマネジメント・AI 駆動開発・AI エージェント開発・心理学・行動心理学などを、
まとめて学び直す必要が出た。手軽に読めて、薄くなく、基礎から応用までそろったものが見つからなかった。

## 一言で
隙間時間に1レッスンずつ読み進めるだけで、学問と一次情報に基づく、基礎論から応用までの知識が得られる、社会人のための独習プラットフォーム。
今の「LLM のしくみ」は、その中の1つの講座になる。

## 誰のために
- 最初の読者は、自分と同じ立場の人(複数の分野を学び直す必要がある、事業会社の PM など)。最初の利用者は自分。
- 目的は「まず自分が使う道具」。外に出すのは、数か月使って、続けられるか・役に立つかを確かめてから。

## 約束すること(特徴の中心)
1. **根拠が見える**: どの記述も、根拠の種類(論文・公式資料・原著・教科書・事例)と、確認の程度(原文を読んだ/一部/独自の整理/未確認)が見える。
   「AI が書いた」ことも隠さず、確認の状況を公開する。これを弱みでなく、強みにする。
2. **基礎から応用への道筋がある**: 分野ごとの講座を、基礎 → 実践 → 応用の段階で並べる。
3. **隙間時間で続けられ、体系もたどれる**: 1レッスンは短く読み切れる。進捗・復習・クイズで定着させる。体系を順にたどることも、隙間時間に1つずつ読むこともできる。

## 根拠の基準は、講座によって変える
| 講座の性質 | 例 | 根拠の基本 |
|---|---|---|
| 技術・実証的な分野 | LLM、AI エージェント、AI 駆動開発、ソフトウェアエンジニアリング、セキュリティ | 論文、公式ドキュメント、標準 |
| 学術的な分野 | 心理学・行動心理学 | 査読論文。追試できていない研究は、そう明記する |
| 実務・事例の分野 | 経営・戦略、マーケティング、マネジメント、プロダクトマネジメント | 教科書、原著、一流の実践者の著作、事例。根拠の種類を表示する |
| 法令・基準の分野 | 法務、労務、会計、監査、経理、経営企画 | 条文・基準そのもの。確認日と改正の有無を必ず付ける |

## 高リスクの分野(法務・労務・会計・監査など)の扱い
- 範囲は「全体像と考え方」に限る。個別の事案の判断は扱わない。
- 根拠の条文・基準と、確認した日を必ず示す。法令や基準は変わるので、確認日が古いものを警告する(今の出典の仕組みを使う)。
- 「個別の判断は専門家に確認を」の線引きを、明記する。

## 分野(講座)の候補
- **ある**: LLM(第1部)、AI エージェント開発(第2部、発展編)、AI を使った開発(第3部)
- **プロダクト・事業**: プロダクトマネジメント、経営・戦略、マーケティング、マネジメント
- **人**: 心理学、行動心理学
- **技術**: ソフトウェアエンジニアリング、セキュリティ
- **バックオフィス**: 法務、労務、会計・経理、監査、経営企画

## 最初の一歩
全分野を「序論」程度で並べ、**メニューと講座の目次だけ**を作って、全体のデザインを見る(本文は書かない)。
- 構造は、分野 → 講座 → 基礎/実践/応用の段階 → レッスン。
- 確かめたいこと: メニューで迷わないか、基礎から応用への道筋が見えるか、根拠の表示が目次の段階でも伝わるか。

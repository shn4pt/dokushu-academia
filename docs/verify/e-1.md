## 出典の記録の点検
- Sackett の項目は how が read で url は bmj.com だが、実際は bmj.com を読まず、第三者の PDF の写しを読んだ(note には書いてあった)。→ 書誌と写しを、別の項目にした。
- OSC は how が search で、要旨のみと明記されており、実態に合っている。
- 取得できなかった資料はない。OSC の本文(Science 掲載)は読んでいない。

## 対応(2026-10-09)
1. 定義を「現時点で最良の根拠」に直した。
2. 「最良の根拠」の読み方、表のまとめ方、「判断する人」への広げ方、「複数の研究を見る」進め方を、「このサービスの整理」と明示した。
3. 治療の問いでも RCT を待てない場合があることを足し、「しばしば誤った(偽陽性の)結論を導く」に直した。「見つからない」を「実施されていない」に直した。
4. 判断を決めるのは「臨床の専門性」と、論説の言葉に直した。
5. 「査読」を削除し、「学術誌に載った」に直した(見出し、判定問題、クイズ、用語集)。OSC の 47%・39% を足し、36% の読み違えを避けた。
6. 一次・二次の判定問題で、新聞の記事は、読む目的によって一次にもなると明記した。定義への当てはめの項目は、そう明記した。
7. 出典の記録を、書誌(search)と、第三者の写し(read)に分けた。

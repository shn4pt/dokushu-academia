# 別の目の確認: lb-5(2026-10-12)

対象: `src/content/lb-5.md`(労務-5 ハラスメント防止の考え方)。高リスクの分野(法令)のため、執筆とは別のエージェント(Opus)が、e-Gov の条文(労働施策総合推進法、男女雇用機会均等法、育児・介護休業法、労働契約法の現行の版と、比較のための旧版)を、実際に取得して突き合わせた。

## 結論
重大な誤り(条番号の取り違え、数字の誤り、条文と逆の記述)はなかった。「ハラスメント」の語が 3 つの法律の本文にないこと(本則、附則、見出しを含めて 0 件)と、2026-10-01 の版が顧客等の規定(第 33・34 条)を含む現行の版であることも確かめられた。直したのは、(1)均等法第 15 条の引用(休業の「請求」は第 65 条第 1 項だけ。「その雇用する女性労働者に対する」の補い)、(2)指針の根拠(育児・介護休業法は第 25 条ではなく別の条。読んでいない、と明記)、(3)第 34 条の責務は「他の事業主が雇用する労働者に対する言動」についてであること、(4)育児・介護休業法の紛争の仕組みを読んでいないこと。判定問題・クイズの正解は、条文に整合していた。

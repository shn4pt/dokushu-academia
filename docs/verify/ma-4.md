# 別の目の確認: ma-4(2026-10-10)

対象: `src/content/ma-4.md`(マーケティング-4 効果測定の考え方)。執筆とは別のエージェントが、OpenStax *Principles of Marketing* の m00018・m00091・m00107 の本文と CNXML を照合し、本文中のすべての計算を検算した。

## 結論
本文の計算はすべて正しい(売上成長率、CSAT、CLV の 4 セグメントと Z 世代の仮定、インプレッション、ROAS、CPA、クイズ 4 問)。本文が「教科書の計算の誤り」とする 2 か所(コンバージョン率 100,000 ÷ 500,000 = 20%、相対市場シェア 5% ÷ 8% = 62.5%。金額と 8% の食い違い)は、CNXML の数式で、本当に誤りだと確認された。そのほかの教科書の計算例に誤りはない。

## 指摘と対応
| 指摘 | 対応 |
|---|---|
| **コンバージョン率の基準(2〜5%、10% 超)に、出典がない、と書いたのは誤り。脚注 11(Statista の、オンライン購入者の端末別の率)がある。直帰率 40% には脚注がない** | 書き直した(脚注はあるが、条件は示されず、「従来のマーケティングで 2〜5%」を裏づけるようには見えない)。判定問題も直した |
| 「教科書は指標と KPI を区別する」は、計画の節に限る。広告・オンラインの節では用語が揺れる | 限定した |
| 「前年同期」は教科書にない(月次または季節ごとに前の季節と比べる) | 直した |
| 「CTR などの式」は言い過ぎ。CTR は定義だけ | 直した |
| 「誤解を招きうる」は原文が somewhat misleading | 「やや」を足す(下記の確認済み) |
| 金額(100 万ドルと 150 万ドル)は本文の文章にある | 足した |

## 確認した範囲
- クイズ 4 問は、すべて正解が先頭の選択肢である(選択肢がシャッフルされるかは、アプリの仕様による)。
- 教科書が引く外部資料(Statista の統計、ブログ、企業の事例)は読んでいない(本文で断っている)。

# 別の目の確認: ac-1(2026-10-10)

対象: `src/content/ac-1.md`(会計-1 序論:会計は何を伝えるか)。高リスク(法令・基準)の講座。執筆とは別のエージェントが、e-Gov の会社法・会社計算規則の全文(API)と、OpenStax *Principles of Accounting, Volume 1* の本文と照合した。

## 結論
条文の引用(会社法第 431・432・435 条、会社計算規則第 3・59 条)、条番号、日付(会社法の現行の版 2026-08-12 施行、将来の 5 つの改正、会社計算規則 2025-03-31 施行、将来の改正なし)、OpenStax の説明、判定問題・クイズの正解は一致。将来の 5 つの版で第 431・432・435 条が現行と同じ文言であることも、別に版ごとの本文を取得して比較し、確認した。範囲と根拠の書き方を次のとおり直した。

## 指摘と対応
| 指摘 | 対応 |
|---|---|
| 「法務省令にあたるのが会社計算規則」は広すぎる(事業報告の省令は別) | 「会社の計算に関する事項を定めているのが会社計算規則。事業報告の省令は読んでいない」に直した |
| 「キャッシュ・フロー計算書を含みません(第 59 条)」は、第 59 条が書いているのではなく、第 435 条第 2 項と第 59 条第 1 項の列挙にない、という読み | 根拠を書き直した(判定問題の解説は、第 59 条の列挙を指しており、そのまま)。連結・臨時計算書類は読んでいないことを足した |
| 日米対応表の「本文では扱わない」は言い過ぎ(教科書の列挙に Disclosures がある) | 直した |
| 教科書の名称は Statement of Owner's Equity | 名称を直し、「おおむね対応」と添えた |
| 銀行の例は「求めることがある」 | 直した |
| 「会社法の条文は基準の中身を定めていない」は範囲が広い(会社計算規則には評価の規定がある)。基準設定機関の名は出典で確認していない | 第 431 条に限定し、機関名を外した |
| 「貸借対照表に入る」は教科書の例からの読み取り | 「教科書の例では」と添えた |

## 確認した範囲
- 基準そのもの(企業会計基準委員会・企業会計審議会の文書)は読んでいない(サイトに接続できない、または日本語 PDF の文字を取り出せなかった)。本文で断っている。
- 人の確認: 高リスクの分野なので、公開後も、本人が全文を読むことを前提にしている。

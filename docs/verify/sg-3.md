# 別の目の確認: sg-3(2026-10-09)

対象: `src/content/sg-3.md`(経営-3 競争環境の分析)。執筆とは別のエージェントが、OpenStax Principles of Management の 5 つの力の節(CNXML の原稿)と、HBR の Porter 論文のページの要旨(説明文)を、逐語で照合した。

## 結論
重大な誤りは 0 件。教科書の定義・5 つの力の説明・例と、要旨にもとづく 5 項目は、原典と合った。「自社の分析ではなく」という整理の配置、判定問題の根拠、日本語の読み違い(受け身)を、すべて直した。

## 指摘と対応
| 指摘 | 対応 |
|---|---|
| 「自分の会社を分析する道具ではなく、業界の利益の構造を読む道具」は、教科書(自社のミクロ環境を理解する道具として紹介)と食い違い、Porter の結論のように読める | 「このサービスの整理です」と明示し、教科書の紹介を先に書いて、「主に〜として扱う」に弱めた |
| 判定問題「技術や規制が変われば」の根拠が、要旨に合わない(要旨が触れるのは政府の政策) | 項目と根拠を「政府の政策」に直した。注意 3 に、技術や顧客の変化は要旨にない、と書き分けた |
| ソニーの例の「高い価格を求められる」は、受け身で逆に読める | 「高い価格を付けられる(力がある)」に直した。判定問題の状況も、教科書の例に近づけた |
| 注意 4 の SWOT が「外部環境を見る道具」では不正確 | VRIO・PESTEL・SWOT を、それぞれ書き分けた |
| 「5 つの力は互いに影響し合う」は、図の矢印(中心の競争と他の 4 つの間)を超える | 図の通りに書き直した |
| 判定問題(乗り換えの費用)の根拠が、選択肢の多さと混ざる。量の方向は本文に明示がない | 根拠を直し、費用が大きいほど移りにくいと足した |
| 「業界の競争を決める」は教科書の語ではない。「要旨が挙げる例」は、要旨が説明を予告する点。「合併・買収」 | それぞれ直した |
| クイズ 3 の解説の末尾が、要旨の内容ではなく整理 | 「要旨には、そのような主張はありません」に直した |

# 別の目の確認: se-3(2026-10-12)

対象: `src/content/se-3.md`(セキュリティ-3 Web アプリの代表的な脆弱性)。執筆とは別のエージェントが、OWASP Top 10:2025 のトップページ、序論、A02・A03・A05 の項目のページを curl で取得して照合した。取得できなかった資料はない。

## 結論
項目の順位、2021 年からの変化、数字(3.73%、100%、3.00%、50%)、本文が挙げた 2 つの食い違いは、出典どおりだった。出典の取り違え 1 件、限定の抜け 1 件、言い方の強さ 2 件を直し、ほかの食い違いを追記した。

## 対応
- 位置づけの文の出典を「トップページ」に直し、トップページを出典の記録に加えた。PM の問い 4 も、トップページと序論に分けて書いた。
- 「何年も」を「数週間から数年」に、手作業の数え方を「1 回しか挙げない傾向」に直した。クイズの解説も合わせた。
- パラメータ化の注意を、ストアドプロシージャの中の話に限定した。
- A03 の食い違い(CWE の数 5 と 6、平均の発生率 5.19% と 5.72%、序論の「出現が最も少ない」とページの「発生率が最も高い」)を限界の節に書いた。A03 の表の数字は、自分でも取得したページで確かめた。

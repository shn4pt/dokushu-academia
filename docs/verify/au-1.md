# 別の目の確認: au-1(2026-10-12)

対象: `src/content/au-1.md`(監査-1 序論:なぜ監査が必要か)。高リスクの分野(法令・基準)のため、執筆とは別のエージェント(Opus)が、e-Gov の条文(現行の版と将来施行の版 16 本を取り直した)、金融庁の PDF(監査基準 2020、内部統制の基準 2023、2026-10-02 の監査部会の草案)を自分で取得して、照合した。

## 結論
条文の引用、第 2 条第 6 号の数字、責任の表、意見の種類の表、将来の版の数と比較の結果、草案の記述は出典どおりだった。出典の取り違え 1 件(合理的な保証)、書き方が誤解を招く箇所 2 件(第 328 条の比較表、第 27 条の 59 の時期)、条文の要約の抜け 2 件(登録の要件、第 26 条の 3 の変更点)、出典にない定義 1 件(監査リスク)を直した。

## 主な判定
| 主張 | 判定 |
|---|---|
| 監査の目的、「適正」に含まれる合理的な保証の判断、一般基準、実施基準の基本原則 1〜7、意見の種類の表、責任の表 | 裏づく |
| 「合理的な保証」の説明(絶対の保証ではなく、十分かつ適切な証拠…) | 出典の記録にない別の基準(内部統制の基準 III.1)からだった。「絶対の保証ではなく」はどの基準の本文にもない |
| 監査リスクを「重要な虚偽表示を見逃して誤った意見を述べるリスク」 | 出典に書かれていない |
| 試査 | 一部だけ(原文は「リスクに対応した監査手続を、原則として試査に基づき」) |
| 第 193 条の 2 第 1 項の要約 | 一部だけ(登録を受けた者に限る旨の括弧書きが抜けていた) |
| 比較表「大会社(類型により、公開会社でないものも)」 | 誤解を招く(第 328 条第 2 項は公開会社でない大会社に常に義務を課し、委員会型の会社は第 327 条第 5 項。読んでいない) |
| 第 2 条第 6 号(5 億円・200 億円)、第 337・396 条、公認会計士法第 2・47 条の 2 | 裏づく |
| 第 193 条の 2 → 第 26 条の 3(2027-04-01) | 裏づく(変更点の例示が足りなかった:特定発行者の定義、外国公認会計士) |
| 第 27 条の 59 は 2028-06-13 の版で現れる | 誤解を招く(初出は 2027-07-22 の版) |
| 将来の版の数(金商法 8、会社法 5、公認会計士法 3)と、読んだ条文の同一性 | 裏づく |
| 草案(継続企業の前提、不正は実務指針、2028 年 3 月決算、日付は空欄) | 裏づく |

## 対応
- 「合理的な保証」の説明を、内部統制の基準の内部統制監査の目的の記述に帰属させ、出典の記録に加えた。「全ての誤りや不正を見つけることを約束するものではない」という言い方は、このサービスの理解だと明記した。
- 監査リスクの括弧書きの定義を削り、実施基準の言葉(発見リスクの水準、監査上の重要性)に直した。試査の書き方を原文に合わせた。
- 第 193 条の 2 の要約と比較表に、登録の要件を足した。比較表の第 328 条の行を、委員会型の会社の条文は読んでいないと明記した形にした。「(現行の版で)」を足した。
- 第 26 条の 3 の変更点の例示に、特定発行者の定義と外国公認会計士の括弧書きを足した。第 27 条の 59 を「2027-07-22 施行の版から」にした。草案の不正の記述を「個別具体的な対応を実務の指針で」にし、日付が空欄であることを書いた。
- 指摘のうち、施行規則との対応(au-2)、第 27 条の 59 の初出、第 26 条の 3 の変更点は、取得済みの e-Gov のデータで、自分でも確かめた。

# 別の目の確認: pm-6(2026-10-10)

対象: `src/content/pm-6.md`(PM-6 プロダクト戦略)。執筆とは別のエージェントが、Cagan(SVPG)の 2020 年と 2008 年の記事、Atlassian の記事の取得テキストと照合した。

## 結論
日付・題名・4 つの要件・Rumelt の引用・Atlassian の構成要素と戦略の種類は一致。条件の省略や言い過ぎを直した。

## 指摘と対応
| 指摘 | 対応 |
|---|---|
| 【中】「自分で提案する」は、原文では「上から降りてくる場合もある(特に創業者がビジョナリーのスタートアップ)。そうでなければ提案する」という条件つき | 条件を添えた |
| 【中】「示唆に富む文書」は visionary の訳がずれ、ビデオを「文書」と括るのも不正確 | 「ビジョンを描き、説得するためのもの(形は…)」に直した |
| 【中】「共通するのは…選ぶ・集中する」は、2008 年の記事に記述がなく、言い過ぎ | 共通点を「機能の一覧ではなく、ロードマップとは別のもの」に絞り、選ぶことは 2020 年だけと明記した |
| 冒頭の「定義は違います」と後段の「変更か使い分けか不明」で強さが不揃い | 冒頭を「違って見えます」に弱めた |
| Atlassian に「戦略は洞察から」の強調がない、は言い過ぎ(市場調査・顧客の声に触れる) | 「やらないことを決める」の強調がない点に絞り、効果を断定するが根拠がない点を添えた |
| 不満を言ったエンジニアは直接の引用ではなく要約 | 要約と分かる書き方に直した |
| 「力のある」は empowered の訳として弱い | 「権限を与えられた」にした |
| クイズ 2 の解説が PM-4 の出典に依存 | 該当の一文を、このレッスンの範囲の記述にした |
| Atlassian の公開・更新日は、取得テキストになく確認できない | ページのメタデータ(datePublished・dateModified)による。記録に明記した |
| Rumelt の引用の順序と "difficulty" の落ち | 大意と断っているので許容 |

# 別の目の確認: ac-2(2026-10-10)

対象: `src/content/ac-2.md`(会計-2 貸借対照表と損益計算書)。高リスク(法令・基準)の講座。執筆とは別のエージェントが、e-Gov の会社計算規則の全文(API)と、OpenStax の本文と照合した。

## 結論
条文の内容(第 5・6 条、第 73〜76 条、第 88〜94 条)、5 段階の利益の式、架空の会社の数字の計算(4,000 → 1,500 → 1,400 → 1,000 → 700、資産 10,000 = 負債 5,000 + 純資産 5,000)、項目の区分、OpenStax の記述、判定問題・クイズの正解は一致。次を直した。

## 指摘と対応
| 指摘 | 対応 |
|---|---|
| 条文の適用範囲の説明が不正確(引いた条文には連結・持分会社の規定も含まれる) | 「連結や持分会社を含めて定めている。このレッスンは、株式会社の個別の場合だけを説明する」に直した |
| 当期純利益の式に、法人税等調整額と、更正・決定による納付・還付の扱いが落ちている | 「法人税等調整額を含む。納付・還付の額も加減する。全部は書いていない」と直した |
| 「それ以外は 1 年内で区分」は言い過ぎ(商品などは種類で列挙) | 「種類で挙げたり、1 年内かどうかで分けたり、項目ごとに書き分けている」に直した |
| 教科書の利得・損失と規則の特別利益・特別損失の対応の断定(営業外収益・費用の一部にも近い) | 「対応は一対一ではない」と直した |
| 例の読み方: 営業利益から当期純利益への減少には、営業外の差し引き、特別損失、法人税等が効く | 直した |
| 「将来施行の改正は見当たらない」の根拠が資料にない | e-Gov の版の一覧で、現行の版以外に施行前の版がないことを確認したと書いた(会社法側の 5 つの改正とは別) |
| 「税務上の利益」は出典に書かれていない | 「このサービスの補足」と明記した |
| 「建物・設備」のラベルが曖昧 | 「建物・機械設備」に直した |

## 確認した範囲
- 基準そのものは読んでいない。連結、上場会社、中小企業向けの扱いは、説明していない(本文で断っている)。

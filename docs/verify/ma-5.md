# 別の目の確認: ma-5(2026-10-10)

対象: `src/content/ma-5.md`(マーケティング-5 ブランドの考え方)。執筆とは別のエージェントが、OpenStax *Principles of Marketing* の m00058・m00059 の本文と、CNXML の脚注の位置で照合した。

## 結論
事実の誤りは 0 件。数値と計算(粗利益率 44%、純利益率 24%、検算の約 36%・約 14%、クイズの 37.5%)はすべて正しい。「根拠が示されていない」と書いた箇所は、CNXML の脚注の位置で確認し、脚注がないことが確かめられた(m00059 には脚注が 0 個。m00058 の脚注は Tide の販売額、Keller、商標、McKinsey、Trader Joe's)。条件の省略と言い過ぎを直した。

## 指摘と対応
| 指摘 | 対応 |
|---|---|
| 「利益率はブランドの価値の一部」は、教科書の位置づけと違う(独立した節) | 「事業の収益性を測る財務の指標として扱う」にした |
| 筋金入りの忠実者の「価格をあまり気にせず」は、カタログ購入の例の中の話。「周りにも勧める」は often | 条件を足した |
| 「便利さが大事な製品」は convenience products(最寄品)の訳として広い | 「最寄品(convenience products)」にした |
| サンドイッチの検算は、費用が同じという前提 | 明示した |
| 「根拠を示していない」は、教科書が理由は述べるため厳密でない | 「理由は述べるが、実証や出典は示していない」に揃えた |
| ブランド価値の評価は「会社が売られるとき」に限る / ブランドの上昇は「広告」でなく「キャンペーン」/ 複数ブランドのリスクに「棚を取れない」 | 直した |

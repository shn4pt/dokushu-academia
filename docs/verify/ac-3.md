# 別の目の確認: ac-3(2026-10-10)

対象: `src/content/ac-3.md`(会計-3 キャッシュフローの見方)。高リスク(法令・基準)の講座。執筆とは別のエージェントが、e-Gov の財務諸表等規則の全文(API)と、OpenStax *Principles of Accounting, Volume 1* の本文と照合した。

## 結論
条文の内容(第 1 条、第 8 条第 18・19 項、第 110〜119 条)、法令番号・法令 ID・施行日(2026-08-07)・施行前の版なし、OpenStax の説明、架空の会社の計算(営業 +1,100、投資 −1,200、財務 +500、増加額 +400、1,600 → 2,000、会計-2 の数字との整合)、判定・分類・クイズの正解は一致。次を直した。

## 指摘と対応
| 指摘 | 対応 |
|---|---|
| **「どの会社が作る必要があるか読んでいない」が、読んだ第 111 条と食い違う**(第 111 条は「連結財務諸表を作成していない会社が作成する」) | 第 111 条の内容を書き、読んでいないのは「規則の対象にあたるか、連結を作る会社にあたるか、連結の規則」と範囲を絞った(「言えないこと」、判定問題の解説も) |
| フリー・キャッシュ・フローの教科書の定義は1つではない(配当を引かない形も使う) | 「流動性の節の定義」と限定し、別の形も使うと書いた |
| 「資金の調達もあわせて見る」は教科書の助言ではない | 教科書は資金調達の例も挙げる、という事実の形に直した |
| 「現金の流入が大きく少ない」は不自然 | 直した |
| 確認の記録が、実際に使った OpenStax の範囲より狭い | 足した |
| 第 113 条と第 117 条の (1)(2) の番号が紛らわしい | 「第 1 号」「第 2 号」にした |
| 特別損失 400 をすべて固定資産売却損と仮定している | 仮定だと書いた |

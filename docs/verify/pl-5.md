# 別の目の確認: pl-5(2026-10-10)

対象: `src/content/pl-5.md`(経営企画-5 M&A と提携の考え方)。OpenStax *Principles of Management* の m70715・m70638・m70654 と、会社法(第 2 条第 27・28 号、第 748 条、第 767 条、第 774 条の 2)。執筆とは別のエージェントが照合した。

## 結論
外部の 5 つの方法と欠点、国際的な戦略的提携の利点と失敗率、会社法の定義と条文の引用(第 748 条は一字一句一致)、日付、教科書の「合併・買収」と会社法の用語がそのまま対応するとは限らない、という記述、分類・クイズの正解は一致。第 2 条と第 748 条が将来施行の 5 つの版で同じ文言であることは、執筆者が版ごとの本文を取得して比較した(別のエージェントの資料には版ごとの本文がなく、その点は再確認できていない)。次を直した。

## 指摘と対応
| 指摘 | 対応 |
|---|---|
| **「成果を示す研究は示していない」は、提携については事実に反する**(教科書は、韓国のデータを調べた研究が、提携で生産性が高まったと報告した、と一文で触れる。数字はない) | 「M&A の成果を示す研究は示していない。提携は一文で触れるが、数字はなく、研究は読んでいない」に直した(言えないこと、判定問題の解説) |
| 「主な理由 2 つ」は狭い(教科書は "A major reason"、さらに曖昧さと不確実さも挙げる) | 「理由として挙げ、さらに…」に直した |
| 判断の軸の表で、「速い(教科書)」は外部の方法全般の利点の転用。ライセンスの速さは推論。評価の大中小はすべてこのサービスの判断 | 書き分け、注記を直した |
| Walmart の買収先を競合と読める | 「競合の買収」と Walmart の例を分けた |
| 「5 つに分ける」は網羅的な分類に読める。Acer が唐突 | 「5 つを挙げる」に直し、Acer を外した |

## 確認した範囲
- 合併などの手続きの要件、競争法の審査、税は読んでいない(本文で断っている)。教科書の事例の事実は確認していない。

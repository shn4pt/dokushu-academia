# 別の目の確認: e-4(2026-10-09)

対象: `src/content/e-4.md`(根拠-4 エビデンスの強さの比べ方)。執筆とは別のエージェントが、Cochrane Handbook v6.5 第 14 章の生の HTML を curl で取得し、テキスト化して、本文の主張と逐語で照合した。確実性の計算(`src/data/grade.ts`)は、手計算で確かめた。

## 結論
数字の写し間違い、出典と逆の主張は、なかった。判定問題の 6 つの答え(高・中・低・中・低・非常に低)は、計算と手計算で一致した。要修正は 6 件、確認した範囲の指摘が複数あり、すべて対応した。

## 指摘と対応
| 指摘 | 対応 |
|---|---|
| 「GRADE は、医療の介入の効果の根拠を評価するために作られた」は、第 14 章にない | 「ハンドブックは、GRADE を、介入(診断検査を介入として評価する場合を含む)の効果の根拠の評価に使っている」に直し、ほかの分野への当てはまりは、このサービスの注意と明記した |
| 大きな効果の説明が原文より弱い(RR>5 / <0.2 の非常に大きな効果、効果が十分大きければ「高」まで、が抜けている) | 足した。クイズの解説も直した |
| 判定問題 4 の「効果が非常に大きく」は、ハンドブックの用語(very large = RR>5)と食い違う | 「効果が大きく(たとえば相対リスクが 2 を超える)」に直した |
| デモが、ハンドブックの認める「下げたランダム化試験を上げる」例外を扱わない。上げる要因が 1 つにつき 1 段階である簡略化と、「ほかに方法上の問題がない」という条件を確かめないことの断りも足りない | デモを直し、下げたランダム化試験にも、上げる要因を使えるようにした(上限は「高」)。断りに、簡略化した点を明記した。テストも更新した |
| 「2 人が独立に評価…求めています」は強すぎる(原文は ideally) | 「理由の記録は必須、2 人が独立に評価して合意するのが望ましい」と書き分けた |
| 各要因の例は、14.3 節の Table 14.3.a の文なのに、出典の記録は 14.2.1〜14.2.3 としか書いていない | 本文と出典の記録に、14.3 節の表を足した |
| ROBINS-I の「実質は同じ結果」、ヘルメットは「中とされる」、不精確さの「大きな」、公表バイアスの例の「ばかり」は、原文より強い | それぞれ、「ハンドブックは、両者は矛盾しないとしている」「中の確実性の根拠にあたる、と示している」「無視できない大きさの」「いくつかあるが…公表されていないかもしれない」に直した |
| 上げる要因の 3 つ目に、もう 1 つの型(関連が示されなかったが、バイアスがすべて関連を大きく見せる方向。メトホルミンの例)がある | 足した |
| 出典の記録の GitHub の URL は、未公開のうちは存在しない | push で解消する。use の説明も、「ハンドブックの規則そのものとの照合ではない」と直した |

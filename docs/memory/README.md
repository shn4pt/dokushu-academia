# 記憶の引き継ぎ用コピー

Claude Code の自動記憶(端末ローカル)の写し。作業端末を変えるときに使う。

## 新しい端末での取り込み

Claude Code に「`docs/memory/` の記憶を、このプロジェクトの記憶に取り込んで」と頼む。
手で入れる場合は、`MEMORY.md` 以外のファイルと `MEMORY.md` を
`~/.claude/projects/<このプロジェクトのパスを `-` でつないだ名前>/memory/` に置く。

## 更新のルール

記憶を更新したら、このコピーも同じ内容に更新して commit する(正本は記憶側、これは写し)。

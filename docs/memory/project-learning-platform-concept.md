ユーザーはこのアプリを、LLM を1講座とする「AI と作る独習プラットフォーム」に広げたい(2026-10-09 のインタビューで合意)。詳細は docs/concept.md。

要点: 最初の読者は自分と同じ事業会社の PM、目的はまず自分が使う道具(外に出すのは数か月使ってから)。信頼は今の方式(AI 執筆+出典・確認状況の公開)を広げ、「根拠の見える化」を特徴の中心にする。根拠の基準は講座ごとに変える。法務・労務・会計・監査は「全体像と考え方」に限り、条文と日付を必ず示す。構造は、分野ごとの講座を基礎→応用で並べる。最初の一歩は、全分野の序論として「メニューと講座の目次だけ」を作ること。名前は「独習アカデミア」に決定(2026-10-09。「大学」は学校教育法第135条第1項の関係で避けた)。公開 URL(mygame1)は未変更。

**Why:** PM として経営・マーケ・心理学・AI 開発などを学び直す必要が出たが、基礎から応用まで根拠のあるまとまった教材がなかった。
**How to apply:** 新しい分野や構造の提案はこの方針に沿わせる。個別の事案の判断や、根拠のない断定を足さない。出典の仕組み([[feedback-sources-honesty]] があれば参照)を新分野にも使う。

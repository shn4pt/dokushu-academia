PR のマージや作業の区切りで報告するとき、最後に「Codex になんと伝えるか」の貼り付け用の文を、常に付ける。

**Why:** ユーザーは Codex(PM 役)との間の橋渡しをしていて、毎回「なんと伝えたらいいか」を聞かずに済ませたい(2026-10-15)。
**How to apply:** 報告の末尾に、コードブロックで、Codex へ渡す完了状況・未検証・次の依頼を簡潔に書く。依頼コメントを PR に投稿済みなら、その旨も添える。

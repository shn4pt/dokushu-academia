独習アカデミアの運営の制約(2026-10-09 に本人が回答):
- 運営に使える時間は週 3〜5 時間。
- 追加の費用は月数千円まで(公開は GitHub Pages の無料枠。AI の利用は、本人の Claude の契約の範囲が基本)。
- 公開前に本人が必ず確認するのは、高リスクの分野(法令・会計など)と、方針(講座の構成・優先度)だけ。ほかのレッスンは、自動の検査と出典の記録で決める。**(2026-10-10 に一部変更: 対話中の push は承認なしで進めてよくなった。無人の定期実行は作らない。高リスク分野の扱いは [[project-writing-progress]] を参照)**
- 公開は、講座単位(段階ごと)でまとめて行う。

**Why:** 個人で、低コストで、継続的に運営するため。
**How to apply:** 講座づくりの手順や仕組みは、本人の時間と判断を最小にする設計にする(確認の材料を1つにまとめる、自動検査で止める、費用のかかる定期実行は避ける)。高リスク分野は必ず本人の確認を挟む。関連: [[project-learning-platform-concept]]

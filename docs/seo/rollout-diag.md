## 5. 基盤が見つけた不具合と、修正

**不具合**: `/catalog/` の初期 HTML で、ナビゲーションの現在位置の強調(`NavLink` の `class="active"`・`aria-current="page"`)が付いていなかった(開発用ビルドでは、React が「属性がサーバーとブラウザで違う」と警告した)。
- **原因**: サーバーの描画(`entry-server.tsx`)の初期の位置が、スラッシュなし(`/catalog`)で、リンク先が、スラッシュ付き(`/catalog/`。Issue #19 の共通部品)になった後、`NavLink` の判定が、サーバーとブラウザで食い違った。
- **本番相当のビルドでは、警告が出ない**(React は、属性の食い違いを検査せず、直さない)。**初期 HTML の誤りが、そのまま残る**(直接アクセスした `/catalog/` で、強調が付かない)。
- **修正**: サーバーの初期の位置を、ブラウザの URL と同じ形(末尾スラッシュ付き)にした(`src/entry-server.tsx` の 1 行)。**修正前(本番相当): 検査が失敗、修正後: 成功**を確認した。初期 HTML と、引き継ぎの後の DOM の両方で、強調を検査する(`rollout-matrix`)。
- **Issue #19(PR #21)で入った不具合を、Issue #33 の基盤が見つけた**。#19 の診断の対象に、講座一覧が入っていなかったことが、見逃しの理由。**この修正は、基盤の検証で見つかった、局所的な不具合の修正で、教材の意味・演習の振る舞いを変えない**(分離した PR にする判断は、レビューで)。

# 独自ドメイン候補の調査: 取得可能性・更新費用・配信先との適合(Issue #20)

調査の文書。**この PR では、コード、教材、出典、確認日、ライセンス、サイト名、ブランドを変更しない。** ドメインの購入、予約、アカウント作成、ログイン、カートへの投入、問い合わせ、DNS 変更、Search Console 登録、公開は、していない。候補や登録情報は、**公開されている情報を読んだだけ**。登録できる保証はない。Claude の確認は、専門家の監修でも、商標の調査でもない。**ドメインを取得しただけで、検索順位が上がる、AI に引用される、とは約束しない。需要や効果は、検証していない。**

## 0. 要約

- **推奨(1 案): `dokushu-academia.com`**。現在のサイト名(独習アカデミア)と、そのまま対応する。`.com` は、調べた登録業者のすべてで扱われ、配信先の候補(Cloudflare の Workers / Pages)とも、制約なく組み合わせられる。1 年目の費用は、調べた範囲で、約 11 USD(Porkbun)か、約 1,287 円〜(お名前.com の更新料金。登録時の割引は条件つき)。
- **次点: `dokushuacademia.com`**。ハイフンなしで、口頭で伝えるときの誤記は減るが、文字が続いて読みにくい。
- 登録の可能性は、**レジストリの公開データ(RDAP)で「登録記録がない」と確認できた**(2026-10-15)。**これは、登録できる保証ではない**(プレミアム価格や予約語、登録業者側の判断は、確認していない)。実際の可否は、作者が登録業者の検索で確認する。
- **作者に必要な判断**: 候補の採用、継続費用の上限(ドメインは毎年かかる)、登録業者、配信先との組み合わせ(§6)。この調査は、予算の上限を決めていない。

## 1. 前提と範囲

- サイト名は「独習アカデミア」(説明: AIと事業・プロダクトをつくる人の学び直し)。**名前や本文は変えない。**ドメインの候補は、名前の読み(どくしゅう・あかでみあ)から作る。
- 配信先の推奨は `docs/seo/hosting.md`(Cloudflare の静的配信など)。ドメインの登録先と配信先を、同じ会社にする必要は、決めつけない。
- 検索語(AI、PM、PdM など)を詰め込んだだけの名前は、候補にしない(§2 の除外)。

## 3. 登録の可能性: 公開情報での確認

**方法**: 各レジストリが公開している RDAP(登録データの照会 API。`https://data.iana.org/rdap/dns.json` の割り当てから)に、ドメイン名を問い合わせた。ログイン・購入はしていない。`.jp` は、JPRS の WHOIS(`whois -h whois.jprs.jp`)。
**確認日時(UTC)**: 2026-10-15 01:49〜01:51。

| 候補 | 照会先 | 結果 |
|---|---|---|
| dokushu-academia.com | rdap.verisign.com | HTTP 404(登録記録なし) |
| dokushuacademia.com | rdap.verisign.com | HTTP 404 |
| dokushu-academia.jp | whois.jprs.jp | `No match!!` |
| dokushu.academy | rdap.identitydigital.services | HTTP 404 |
| dokushu.study | rdap.nic.study | HTTP 404 |
| (参考)dokushu.com | rdap.verisign.com | 登録済み(2010-04-18 登録、期限 2027-04-18、`client transfer prohibited`) |
| (参考)dokushu-academia.net / .org / .app | 各レジストリ | 404(登録記録なし) |

**不確実性**:
- **「登録記録がない」は、「登録できる」ではない。** プレミアム(高額)価格の文字列、レジストリが予約している語、登録業者の販売停止、直前に他者が登録した場合は、この確認では分からない。
- 404 は、「そのレジストリに登録がない」という応答を意味する。**DNS が応答しないことを根拠に、空きと断定していない**(DNS では確認していない)。
- 登録業者の検索画面での最終確認は、していない(ログイン・カート操作を避けるため)。**作者が、購入の直前に、業者の画面で、価格と可否を確認する。**

## 6. 配信先との適合(`hosting.md` との照合)

| 組み合わせ | 適合 |
|---|---|
| **Workers の静的アセット(第一候補)+ 独自ドメイン** | Workers の Custom Domains は、**有効な Cloudflare ゾーンが必要**(公式資料。apex でもサブドメインでも)。ゾーンに追加するには、ドメインのネームサーバーを Cloudflare に向ける。**Cloudflare Registrar で取得すれば、自動的に Cloudflare のネームサーバーになる。ほかの業者で取得した場合は、ゾーンを Cloudflare に追加し、業者側でネームサーバーを変える必要がある**(業者がネームサーバーの変更を許すかは、Porkbun・お名前.com とも未確認) |
| Pages(代替)+ apex ドメイン | apex は、**ゾーンが Cloudflare アカウントにあること**が必要(公式資料)。同じ制約 |
| Pages(代替)+ サブドメイン(例: `www`) | **外部 DNS に CNAME を向ける経路がある**(ゾーン不要)。この経路は、Workers には当てはまらない |

- **登録先と配信先を、同じ会社にする必要はない**。ただし、Workers を使う場合は、どの業者で取得しても、DNS は Cloudflare に移す(ゾーンを追加する)必要がある。**Cloudflare Registrar を使うと、この手間はないが、DNS を Cloudflare に固定される**(他社の DNS に変えられない)。
- `.jp` を選ぶと、Cloudflare Registrar では取得できないので、別の業者で取得し、ネームサーバーを Cloudflare に向ける形になる(**業者がその変更を許すかは未確認**)。
- メール(独自ドメインのメール)や、将来の販売ページ用のサブドメインを、どこで管理するかは、今回、決めていない。

## 7. 推奨と次点

**推奨: `dokushu-academia.com`**
- **理由**: ①サイト名と 1 対 1 に対応する。②`.com` は、調べた業者すべてが扱い、更新料金も安定している(`.academy`・`.study` のような、2 年目からの大幅な上昇がない)。③配信先(Workers / Pages)と、制約なく組み合わせられる。④講座(分野)が増えても、名前は変わらない。
- **取得先の目安**: Cloudflare Registrar(配信先と同じ。ネームサーバーが固定される代わりに、設定が少ない。at cost だが、金額は、購入時に確認が要る)か、価格が公開されている Porkbun。日本語の窓口を重視するなら、お名前.com。**判断は、作者**。
- **リスク**: ハイフンの伝達。購入の直前に、可否と価格(プレミアムの有無)を、業者の画面で確認する必要がある。

**次点: `dokushuacademia.com`**(ハイフンなし)。

**`.jp` を選ぶ場合**: 日本の読者向けの表示としては有力だが、取得先が限られ、日本国内の住所が必要。

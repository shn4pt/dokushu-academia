# 別の目で、レッスンを確認する

執筆した本人は、自分の書いた主張を疑いにくい。**執筆の文脈を持たない別のエージェント**(Agent ツール、subagent_type は general-purpose)に、確認を頼む。

## 手順
1. 対象のレッスンのファイル(`src/lessons/<Name>.tsx`)と、出典の記録(`src/data/lesson-sources.json` の該当 ID)を指定する。
2. Agent に、次の指示を、自己完結した形で渡す(執筆の経緯は渡さない)。
   - 「本文から、事実の主張(数字、定義、引用、因果、『〜とされる』など)を、すべて箇条書きにする。」
   - 「各主張を、出典の記録にある URL を**実際に取得して読み**、裏づけられるか判定する(裏づく / 一部だけ / 裏づかない / 出典に書かれていない / 取得できず確認できない)。」
   - 「出典の記録の `how: read` が、本当に本文を読めば確認できる範囲か(要旨だけ、検索結果だけで済ませていないか)を疑う。」
   - 「独自の整理・助言と書かれた部分が、文献の主張と混ざっていないか。本文の言い切りが、出典より強くないか。」
   - 「訳語・引用の不正確さ、数字の写し間違い、範囲の拡大(特定の分野の結果を、一般に言っていないか)を探す。」
   - 結果を、「主張 | 判定 | 根拠(出典の該当箇所) | 直す案」の表で返す。ファイルは編集しない。
3. 返ってきた表を、自分でも該当箇所で確かめる(Agent の報告は、そのまま信じない)。
4. 「裏づかない」「出典に書かれていない」は、本文を直すか、弱める。「取得できず確認できない」は、確認できた範囲だけに本文を弱めるか、使わない。
5. 結果の表を、確認の材料(`docs/production.md` の工程 5)に入れる。

## 注意
- 費用: Agent は AI の利用量を使う。1レッスンにつき1回で足りる。
- 取得が遮断される資料は、確認できなかったものとして表に残す。
